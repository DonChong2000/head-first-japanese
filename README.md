## 這是甚麼？

一個玩到失控的笑話。程式員學新語言，都愛翻 Head First（中文版叫「深入淺出」），那日語也來一本吧：對話氣泡、手寫箭咀、「削尖你的鉛筆」、「沒有蠢問題」，一樣不少。

本書的優勢在於善用你已經懂的東西：

- **中文**：漢字的意思你大多已經懂；粵語的入聲（-p、-t、-k）還能幫你掌握日語的促音和音讀。
- **英文**：上千個片假名外來語，你一看就懂。
- **陷阱**：漢字也會騙人，<ruby>手紙<rt>てがみ</rt></ruby>是信，<ruby>勉強<rt>べんきょう</rt></ruby>是讀書。書中會一直提醒你。

## 功能

- **按一下就有讀音**：每個紅色的日文都可以按，由瀏覽器的日語語音讀出來。
- **振假名開關**：右上角的「ふりがな」按鈕可以隱藏漢字讀音，用來自測。
- **即時批改**：練習按「檢查」就有分數；平假名、片假名用錯會另外標示。
- **錄音**：口語練習可以錄下自己的聲音回放，錄音只留在瀏覽器，不會上傳。
- **進度**：每章的「完成本章」勾號存在你的瀏覽器裏。

聽不到聲音的話，要先在系統加入日語語音，做法見[本書使用說明](ch/00-intro.html)。

## 本地開啟與開發

純靜態 HTML，沒有建置步驟，直接用瀏覽器打開 `index.html` 就可以。

```
ch/NN-slug.html   每章一個檔案
book.js           目錄（CHAPTERS）、語音、批改、振假名開關、導覽
style.css         所有方塊和版面樣式
assets/cover.jpg  首頁封面（800 × 1071）
tools/check.mjs   結構檢查：node tools/check.mjs
tools/shot.mjs    截圖（淺色／深色 × 電腦／手機）：node tools/shot.mjs <輸出資料夾> <頁面...>
```

寫新章節前請先看 [AGENTS.md](AGENTS.md)：章節結構、方塊種類、練習格式、文風和詞彙表都在裏面。提交前 `node tools/check.mjs` 必須通過。推送到 `main` 後，GitHub Pages 會自動更新網站。
