第 4 章

漢字：中文母語者的主場與陷阱

你一眼就看得懂的字，日本人卻用另一種聲音讀，有時還換了意思。

田中さん，拿著一個信封カーヤンさん、手紙てがみです。

嘉欣，心想手紙？ 為甚麼有人寄廁紙給我？

嘉欣，拆開信封……是媽媽從香港寄來的信。原來日語的「手紙」是信！

嘉欣，指著雪櫃上的傳單これは何なんですか。

田中さん銭湯せんとうのチラシです。

嘉欣，讀著價錢表「大人」……だい……じん？

田中さん，忍住笑大人おとなです。

嘉欣，心想「大」不是讀 だい 嗎？ 大学だいがく 是 だいがく，為甚麼「大人」又變成 おとな？

中文讀者學日語，最大的優勢就是漢字。日本的街道招牌、車站名、餐牌上的漢字，你一看就大概明白，英文母語的同學要花幾年才追得上。所以日本語學校的老師常說：漢字圈的學生，閱讀起步快得多。

可是嘉欣十分鐘內就中了兩次伏。第一次是意思：「手紙」不是廁紙。第二次是讀音：同一個「大」字，有時讀 だい，有時卻完全不是。這一章就是要拆解這兩個陷阱，再把你的中文腦變成真正的武器：你會發現，廣東話的讀音能幫你猜中很多漢字的日語讀法。

主場優勢是真的，但主場也有地雷。

規則 1：一個漢字，兩種讀法

一千多年前，日本人從中國引進漢字。當時日語早已有自己的口語，於是漢字有了兩種讀法：

  • 音讀：模仿當時的中國讀音。所以音讀聽起來像中文，例如「山」在 富士山ふじさん 讀 さん，跟粵語 saan1、普通話 shān 很像。
  • 訓讀：用漢字去寫日本原有的詞，讀音是日語本身的。「山」在日語本來叫 やま，於是「山」也讀 やま。

看看「人」字在三個詞裏的讀音：

人訓讀 ひと ／ 日本人音讀 にほんじん ／ 三人音讀 さんにん

按一下聽聽：人ひと、日本人にほんじん、三人さんにん。じん 和 にん 都是音讀，聽起來跟普通話 rén、廣東話 jan4 都有幾分相似；ひと 是訓讀，跟中文完全無關。為甚麼音讀有兩個？下面的「中文腦」會解釋。

訓讀的感覺，就像你看到「kg」會讀成「公斤」：寫的是一個借來的符號，讀的是自己的語言。日本人看到「山」，心裏想的是本地話 やま，漢字只是借來寫它的工具。

字典有一個慣例：音讀用片假名寫，訓讀用平假名寫。所以字典會這樣標「山」：サン／やま。這一章的漢字卡和表格也用這個慣例。

中文腦：呉音和漢音，兩批「進口貨」

「人」為甚麼有 にん 和 じん 兩個音讀？因為漢字不是一次過傳到日本的。

  • 呉音：比較早的一批，大約五、六世紀，經朝鮮半島傳入，據說帶著中國南方（古代吳地）的口音。佛經用得最多，也留在很多日常詞裏。
  • 漢音：七、八世紀，日本派遣唐使到長安，帶回當時唐朝首都的標準音。朝廷大力推廣，後來成為音讀的主流。

兩批讀音都保留了下來，按詞語分工：

  • 人：三人さんにん（にん，呉音）／日本人にほんじん（じん，漢音）
  • 生：一生いっしょう（しょう，呉音）／先生せんせい（せい，漢音）
  • 月：一月いちがつ（がつ，呉音）／月曜日げつようび（げつ，漢音）

這有點像廣東話的文白異讀：「行」在「行路」讀 haang4，在「銀行」讀 hang4；「生」在「生日」讀 saang1，在「學生」讀 sang1。同一個字，不同年代、不同層次的讀音並存，靠詞語決定讀哪一個。你早就習慣這種事，只是沒想過日語也一樣。

規則 2：怎樣知道是音讀還是訓讀？

沒有百分百的規則，但有一個八成準的經驗法則：

  • 兩個或以上漢字連在一起（熟語），多數讀音讀：電車でんしゃ、学生がくせい、水曜日すいようび。
  • 一個漢字單獨出現，或者後面跟著平假名，多數讀訓讀：車くるま、水みず、食たべる。

比較這幾對：

漢字單獨（訓讀）熟語（音讀）
車車くるま（汽車）電車でんしゃ（電車）
水水みず（水）水曜日すいようび（星期三）
山山やま（山）富士山ふじさん（富士山）
食食たべる（吃）食堂しょくどう（食堂）

例外有兩種。第一種是訓讀的熟語：日常生活最常用的一些複合詞，兩個字都讀訓讀，例如 名前なまえ（名字）、出口でぐち（出口）、花火はなび（煙花）。留意後兩個的第二個字都「濁」了：くち 變 ぐち，ひ 變 び。兩個詞黏在一起時，後面的字常常加上濁點，日語叫「連濁」，以後會經常見到。

第二種是特殊讀法：整個詞有一個固定讀音，跟個別漢字的讀音拉不上關係。嘉欣碰到的 大人おとな 就是這一種。

小心！整個詞一起背的特殊讀法

這些詞很常用，N5 一定會考，而且拆開來讀一定讀錯：

  • 大人おとな（成年人）：不是 だいじん
  • 今日きょう（今天）、明日あした（明天）、今年ことし（今年）
  • 一人ひとり（一個人）、二人ふたり（兩個人）：三個人以上又變回 三人さんにん
  • 時計とけい（鐘、手錶）
  • お父とうさん（爸爸）、お母かあさん（媽媽）

這類詞的振假名是蓋在整個詞上面的，不能逐個字分配。背的時候把它當成一個新詞，別嘗試拆開。

規則 3：送假名，漢字後面那條「尾巴」

動詞和形容詞的漢字後面，常常跟著幾個平假名，叫送假名。漢字負責不變的部分，送假名負責會變的部分：

食漢字 た：不變べる送假名：會變 ／ 高漢字 たかい送假名

食たべる（吃）到了第 6 章會變成 食たべます，「食」不動，變的只是後面的假名。高たかい（高、貴）到了第 7 章會變成 高たかくない，同樣是尾巴在變。

送假名還有一個重要作用：告訴你這個漢字讀甚麼。同一個漢字配上不同的送假名，讀音就不同：

  • 少すこし（一點點）／少すくない（少）
  • 生いきる（活著）／生うまれる（出生）
  • 入はいる（進入）／入いれる（放進去）

所以讀日語時，眼睛要連漢字和後面的假名一起看，不能只看漢字就猜讀音。

漢字是函式名稱，送假名是參數，參數不同，結果就不同。

削尖你的鉛筆

每個詞的振假名已經給你了。判斷這個讀音是音讀還是訓讀。提示：聽起來像中文的，多數是音讀。

  1. 山やま
  2. 電車でんしゃ
  3. 水みず
  4. 学校がっこう
  5. 花はな
  6. 先生せんせい
答案

1 訓讀、2 音讀、3 訓讀、4 音讀、5 訓讀、6 音讀。

規律很明顯：單獨一個字的都是訓讀，兩個字的熟語都是音讀。でんしゃ 跟粵語「電車」din6 ce1、せんせい 跟「先生」sin1 sang1，一聽就知道是同源。はな 跟「花」faa1／huā 就完全拉不上關係。

規則 4：日本的漢字，有自己的寫法

日本在二次大戰後簡化了一批漢字，叫「新字體」。結果日本漢字大部分跟繁體字一樣，少部分簡化了，而簡化的方法又跟中國大陸的簡體字不完全相同。這一章的核心漢字裏，就有幾個要特別留意：

日本繁體簡體例詞
学學学学生がくせい
気氣气天気てんき（天氣）
駅驛驿駅えき（車站）
読讀读読よむ（讀）
来來来来年らいねん（明年）
会會会会社かいしゃ（公司）
円圓圆百円ひゃくえん（一百日圓）
万萬万一万円いちまんえん（一萬日圓）

看出規律了嗎？学、来、会、万 跟簡體字一樣；気、駅、読、円 則是日本獨有的寫法，繁體和簡體都不是這樣寫。講普通話、習慣簡體字的讀者看 気、読 會覺得「差一點」；習慣繁體字的香港和台灣讀者，則要接受一些字被簡化了。

日圓的符號「¥」，讀音其實就是「円」的 えん。英文寫成 yen，是因為以前的羅馬字拼法。中文說「日圓」，日語只說 円えん。

小心！用日文輸入法打日本漢字

寫日語時，一定要用日文輸入法轉漢字。用中文輸入法打出來的「學生」「天氣」，日本人看得懂，但一看就知道是外國人寫的，正式文件和電郵上很不專業。

還有一些字形差別細到要放大才看得見，例如日本的 毎（每）裏面是「母」，歩（步）下面多了一點。用日文輸入法就不用擔心，電腦會自動給你日本的字形。

手寫時，日本人對這些細節不算太嚴格，但 JLPT 的選項有時會故意放一個中文字形來陷害你。看清楚才選。

削尖你的鉛筆

選出日語的正確寫法。小心，有些選項是繁體字，有些是簡體字。

  1. 車站 →
  2. 天氣 →
  3. 讀 →
  4. 學生 →
  5. 一百日圓 →
答案

1 駅えき、2 天気てんき、3 読よむ、4 学生がくせい、5 百円ひゃくえん。

「元」在日語裏另有意思（例如 元気げんき，精神、健康），不是貨幣單位。日本的錢只用 円。

規則 5：用廣東話猜音讀

現在到了中文讀者的秘密武器。音讀是一千多年前的中國讀音，而廣東話保留了很多古漢語的特徵，特別是字尾的 -p、-t、-k、-m。結果是：知道一個字的廣東話讀音，往往就能猜到它的音讀。

關鍵在字尾。日語的音節大多以元音收尾，古漢語的韻尾傳到日語，就變成了固定的假名：

粵語字尾音讀變成例子
-kく／き六 luk6 → ろく、学 hok6 → がく、食 sik6 → しょく、白 baak6 → はく、駅（驛）jik6 → えき
-tつ／ち一 jat1 → いち、八 baat3 → はち、日 jat6 → にち、月 jyut6 → げつ、出 ceot1 → しゅつ
-pう（古時寫 ふ）十 sap6 → じゅう、入 jap6 → にゅう
-ngう／い東 dung1 → とう、中 zung1 → ちゅう、長 coeng4 → ちょう、生 sang1 → せい、名 ming4 → めい
-m 和 -nん三 saam1 → さん、金 gam1 → きん、南 naam4 → なん、千 cin1 → せん、年 nin4 → ねん、電 din6 → でん

幾點補充：

  • -p 為甚麼變成 う？古時的日語把 -p 寫成 ふ：「十」是 じふ，「入」是 にふ。後來 h 音在詞中間弱化，ふ 變成 う，再跟前面的元音合成長音，就成了今天的 じゅう、にゅう。
  • -ng 變 う 還是 い？大致看前面的元音：元音是 e、i 一類的，多數變 い（生 せい、名 めい、青 せい）；是 a、o、u 一類的，多數變 う（東 とう、長 ちょう）。
  • -m 和 -n 在日語裏合併了，都變成 ん。所以廣東話分得清的「金」gam1 和「斤」gan1，日語都讀 きん。

這不是百分百準確的公式，因為一千年來兩邊的讀音都變了不少。但用來猜音讀，大約七八成會中，而且越猜越準。下次見到一個新的熟語，先用廣東話讀一次，再想想它的日語樣子，你會驚訝自己猜中了多少。

中文腦：講普通話的讀者也有一半武器

普通話早就失去了 -p、-t、-k 和 -m，所以表格的頭三行和 -m 那一行幫不上忙。不過 -n 和 -ng 的分別普通話完整保留了：

  • 普通話以 -n 收尾 → 音讀多數有 ん：三 sān → さん、千 qiān → せん、新 xīn → しん、電 diàn → でん。
  • 普通話以 -ng 收尾 → 音讀多數是長音 う 或 い：東 dōng → とう、中 zhōng → ちゅう、生 shēng → せい、名 míng → めい。

至於入聲字，有一個粗略的提示：普通話讀第二聲、而音讀以 く、つ、ち 收尾的字，很多本來是入聲，例如学 xué、十 shí、白 bái、食 shí。如果身邊有講廣東話、客家話或閩南話的朋友，問他們讀一次，馬上就知道。

用規則 5 的表格，從廣東話讀音推測音讀。（講普通話的讀者，先看看 -n、-ng 那幾題。）

  1. 北 bak1 →
  2. 八 baat3 →
  3. 十 sap6 →
  4. 南 naam4 →
  5. 東 dung1 →
  6. 白 baak6 →
  7. 新 san1 →

1 ほく（東北とうほく）、2 はち、3 じゅう、4 なん、5 とう（東京とうきょう）、6 はく、7 しん（新聞しんぶん）。

-k → く、-t → ち、-p → う、-m／-n → ん、-ng → う，全部照表。開頭的子音也有規律（例如粵語的 b、p 在日語常常變成は行），但那個比較複雜，先把字尾練熟。

動動腦

「学校」粵語讀 hok6 haau6，日語讀 がっこう，不是「がくこう」。第 1 章說過促音和入聲的關係。你能解釋 がく 的 く 為甚麼在這裏變成了 っ 嗎？再想想 一緒いっしょ（一起）和 日本にっぽん：いち、にち 的 ち 又去了哪裏？

為甚麼日本人離不開漢字？

你可能會想：既然假名能寫出所有讀音，日本人為甚麼不乾脆全用假名，像韓國人主要用諺文那樣？

原因之一，正是規則 5 那張表。古漢語傳到日語時，聲調全部丟掉了，-m 和 -n 合併了，很多不同的韻母也擠在一起。結果是，日語的音讀出現大量同音詞：

  • きしゃ：汽車きしゃ（蒸汽火車）、記者きしゃ（記者）
  • こうえん：公園こうえん（公園）、講演こうえん（演講）
  • かがく：科学かがく（科學）、化学かがく（化學）

廣東話靠聲調和韻尾分得清清楚楚的字，日語全部撞在一起。說話時靠上文下理還可以猜，寫成文字，就要靠漢字分辨。日本人甚至會把「化学」講成 ばけがく，故意用訓讀「化ける」來跟「科学」區別。

原因之二，日語寫字時不留空格。漢字夾在假名之間，就像天然的分隔符號：漢字開始，多數是一個新詞；變回平假名，多數是助詞或詞尾。試試讀全部用平假名寫的句子 わたしはにほんごのがくせいです，再讀 わたしは日本語にほんごの学生がくせいです，哪一句讀得快？ 這就是為甚麼兒童讀物全用假名時，要特別在詞與詞之間留空格。

漢字＝語法高亮：一眼就看到詞在哪裏開始。

規則 6：漢字假朋友

回到嘉欣的「手紙」。日語和中文用同一個漢字詞，意思卻不同，這叫「假朋友」。它們特別危險，因為你根本不會想到要查字典：一看就「懂」，結果懂錯了。

小心！看得懂卻意思不同的詞

  • 手紙てがみ：信。廁紙是 トイレットペーパー。
  • 勉強べんきょう：讀書、溫習。不是「勉強去做」。
  • 大丈夫だいじょうぶ：沒問題、不要緊。日本人一天說幾十次，跟「男子漢」無關。
  • 新聞しんぶん：報紙。新聞報道是 ニュース。
  • 汽車きしゃ：蒸汽火車。汽車是 車くるま 或 自動車じどうしゃ。
  • 走はしる：跑。走路是 歩あるく。（廣東話的「走」本來也是跑，香港讀者反而佔了便宜。）
  • 大家おおや：房東。嘉欣的 大家おおやさん 只有一個人，不是「大家」。
  • 娘むすめ：女兒，不是媽媽。

好消息是，這類假朋友的數量有限，N5 範圍內就是這十來個。把它們當成「全新的詞」來背，反而不容易錯。

考試熱身：漢字読み

JLPT N5「文字・語彙」的問題 1，會在句子裏劃線標出一個漢字詞，問你它的平假名讀法。四個選項通常只差一個濁點、一個長音或一個促音。劃線的詞沒有振假名，也不能按來聽，否則就變成送分題了。

  1. これは日本語の本ほんです。
  2. 田中たなかさんは大学生です。
  3. あの男の人ひとはだれですか。
  4. 今日は日曜日にちようびです。
  5. それは新聞ですか。
  6. これは電車のきっぷです。
答案

1 にほんご、2 だいがくせい、3 おとこ、4 きょう、5 しんぶん、6 でんしゃ。

全句讀一次：これは日本語にほんごの本ほんです。 今日きょうは日曜日にちようびです。 これは電車でんしゃのきっぷです。（這是電車的車票。）

出題者最愛的陷阱：清濁（こ／ご、て／で）、大小字（しゃ／しや）、長音（きょう／きよう）。第 3 題的 だん 和 なん 都是「男」真正的音讀，但這裏單獨用，要讀訓讀 おとこ。這正是規則 2：單獨的字讀訓讀。

沒有蠢問題

我看得懂漢字，是不是可以跳過振假名？
剛好相反。你看得懂意思，所以更容易忽略讀音，結果「讀得懂、說不出、聽不明」。第一部分每個漢字都有振假名，請每次都看一眼。覺得自己記熟了，可以按頁頂的「ふりがな」按鈕把它們藏起來，測試自己。
日本人要認多少個漢字？
日本政府定的「常用漢字」有 2,136 個，是報紙和公文的基準，中學畢業大致學完。N1 的程度，也差不多要認識這個範圍。聽起來很多，但對你來說，大部分字的意思早就懂了，要追的主要是讀音。
音讀可以用廣東話猜，那訓讀呢？
訓讀是日本本土的詞，跟中文沒有關係，只能硬背。好消息是，訓讀多數是日常生活最基本的詞（山やま、水みず、食たべる），用得多，自然就記住了。
為甚麼「東京」讀 とうきょう，不是 とうけい？
「京」的呉音是 きょう，漢音是 けい。「東京」選了呉音。けい 也有用：連接東京和橫濱一帶的「京浜」就讀 けいひん。哪個詞用哪個音，只能逐個記，不過用得多了，你會開始有感覺。
手寫漢字，筆順要跟日本的嗎？
大部分漢字的筆順跟香港和台灣教的一樣，少數字有分別（例如「必」）。JLPT 不考筆順，也不考手寫，日常寫得清楚就夠了。真正要花時間的，是讀音。

重點整理

  • 漢字有兩種讀法：音讀模仿古代中國讀音（字典用片假名標），訓讀是日本原有的詞（用平假名標）。
  • 經驗法則：熟語多數讀音讀（電車でんしゃ），單獨的字或帶送假名的多數讀訓讀（車くるま、食たべる）。
  • 特殊讀法要整個詞背：大人おとな、今日きょう、一人ひとり、時計とけい。
  • 音讀常有兩個：呉音（較早，にん、しょう）和漢音（唐代長安音，じん、せい）。
  • 送假名負責會變的部分，也提示讀音：少すこし／少すくない。
  • 日本字形：学 気 駅 読 来 会 円 万，寫日語要用日文輸入法。
  • 用廣東話猜音讀：-k → く／き，-t → つ／ち，-p → う，-ng → う／い，-m／-n → ん。普通話讀者可用 -n／-ng 的分別。
  • 背詞語，不要逐個漢字背讀音表。
  • 假朋友：手紙てがみ 信、勉強べんきょう 溫習、大丈夫だいじょうぶ 沒問題、新聞しんぶん 報紙、走はしる 跑、大家おおや 房東。
