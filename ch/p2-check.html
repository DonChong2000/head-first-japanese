第二部分 自測

N4 自測：第二部分的期末考

普通形、可能形、授受、條件、被動、敬語：八個新模組，現在一起跑整合測試。

這份自測照足 JLPT N4 的題型和次序。跟 N5 比，文字・語彙多了一種題型：問題 5「用法」，考你一個詞放在句子裏用得對不對。題目以第 11 至 18 章為主，也會用到第一部分學過的東西，共 60 題。

怎樣做這份自測

  • 不要偷看。做完一個方塊才按「檢查」，再打開答案。每個選項為甚麼錯，答案都有解釋。
  • 計時。真試每一節的時間以 jlpt.jp 公布為準。建議一口氣由頭做到尾，記下用了多久，下次重做時比較。
  • 聽解只聽一次。按 ▶ 聽完就作答，不要重播。答完才打開答案看文字稿，再自己把文字稿讀出來，最好讀到跟得上錄音的速度。
  • 聽解由瀏覽器朗讀，男女同一把聲音，錄音裏會讀出「男」「女」標明誰在說話。真試要你看圖的地方，這裏改用文字選項或中文情境說明。
  • 由這一部分開始，N5 程度的漢字（人、日、本、行、来、食、飲、見、駅 等）不再加振假名，其他漢字照加。文字・語彙問題 1 和問題 2 的題目句按了不會發聲，被考的詞也沒有振假名。

做不完也不要緊，做到哪裏記到哪裏。

真試的計分方法：N4 滿分 180，合格要 90 分，而且「言語知識（文字・語彙・文法）・讀解」不可少於 38 分，「聽解」不可少於 19 分。考試時間和最新細則請看 jlpt.jp。

言語知識（文字・語彙）

考試熱身：問題1 漢字読み（漢字讀法）

劃了線的詞怎樣讀？選出正確的平假名。

  1. 医者いしゃに、毎日運動したほうがいいと言われました。
  2. 電車に遅おくれますよ。急いでください。
  3. ここで写真を撮とってもいいですか。
  4. 旅行りょこうはとても楽しかったです。
  5. 暑あついですね。窓まどを開けてもいいですか。
答案

1 うんどう：「運」うん，「動」どう，長音寫成 う。うんとう 漏了濁點，うんど 漏了長音，うんどお 是長音寫錯（お段長音多數寫 う）。

2 いそいで：急いそぐ 的て形。きゅう 是「急」的音讀，用在 急行きゅうこう 這類詞，不會跟送假名 いで 連用；いぞいで 多了濁點；およいで 是「泳いで」。

3 しゃしん：拗音 しゃ，「真」不濁。しやしん 把細 ゃ 寫成大 や，多了一拍。

4 たのしかった：「楽」在這裏是訓讀 たの。らく 是 楽らく（輕鬆）的讀法，がく 是 音楽おんがく 的讀法；たのしかた 漏了促音。

5 あけて：送假名是 けて，所以是他動詞 開あける。あいて、ひらいて 是「開いて」（送假名 いて）的讀法；ひらけて 是另一個詞「開けて（ひらけて）」，意思是變得開闊，用不上「窓を」。第 16 章的自他動詞對，送假名就是線索。

考試熱身：問題2 表記（寫法）

劃了線的詞，用漢字應該怎樣寫？

  1. ここにこたえを書いてください。
  2. しゅうまつは何をする予定よていですか。
  3. この荷物にもつはとてもおもいです。
  4. 林はやしさんはりょうりが上手ですね。
答案

1 答こたえ：竹字頭加「合」。合え 少了竹字頭；等、筆 也是竹字頭，但下半部不同，意思也不同。

2 週末しゅうまつ：「末」上橫長，「未」上橫短，中文也一樣分。周 沒有走之底，週来 不是詞。

3 重おもい：重量的「重」。思い 也讀 おもい，但它是「想法」，是名詞，不能說「とても思いです」。動、量 都有「重」的部件，是用來騙你的。

4 料理りょうり：科 跟「料」只差左邊（禾和米）；里 少了王字旁；斗 只有右半。

考試熱身：問題3 文脈規定（按上文下理選詞）

（　）裏面放哪一個最合適？

  1. 財布さいふを（　）しまいました。交番こうばんに行きます。
  2. この道は車がたくさん通とおります。子どもには（　）です。
  3. 旅行りょこうの前に、ホテルを（　）おきました。
  4. 来年、大学の試験しけんを（　）つもりです。
答案

1 財布さいふをおとしてしまいました。 銀包掉了，所以去派出所。はらう 是付錢，こわす 是弄壞，わたす 是交給別人，都跟「去派出所」接不上。

2 子どもにはあぶないです。 車多，對小孩危險。ねむい（睏）、うれしい（高興）、めずらしい（罕見）都說不通。

3 ホテルをよやくしておきました。 旅行前預先訂酒店，～ておく 正是「預先做好」。そうだん（商量）、せつめい（說明）、あんない（帶路）的對象都不會是酒店。

4 試験しけんをうけるつもりです。 應考是 試験しけんを受うける。中文說「考試」，日語不說 試験しけんをとる；はいる 要配 に（大学に入る）；かける 配電話、眼鏡。

考試熱身：問題4 言い換え類義（意思相近的句子）

哪一句的意思跟劃了線的句子最接近？選出號碼。

  1. 弟おとうとは先生にほめられました。
    1. 先生は弟おとうとに「静しずかにしてください」と言いました。
    2. 先生は弟おとうとに「よくできましたね」と言いました。
    3. 弟おとうとは先生に「ありがとうございました」と言いました。
    4. 先生は弟おとうとに「それはだめですよ」と言いました。
  2. ここはちゅうしゃじょうです。
    1. ここに車をとめます。
    2. ここで車を売うります。
    3. ここで車を直なおします。
    4. ここで車を洗あらいます。
  3. この辞書じしょは使つかいにくいです。
    1. この辞書じしょは便利べんりです。
    2. この辞書じしょはあまり使つかいません。
    3. この辞書じしょは使つかいやすくないです。
    4. この辞書じしょはもう使つかえません。
  4. ゆうべは遅おそくまで起おきていました。
    1. きのうの朝あさは遅おそくまで起おきていました。
    2. けさは遅おそくまで起おきていました。
    3. おとといの夜よるは遅おそくまで起おきていました。
    4. きのうの夜よるは遅おそくまで起おきていました。
答案

1 是 2：ほめられる 是 ほめる（稱讚）的被動，老師稱讚了弟弟。1 和 4 是責備，3 方向反了，是弟弟對老師說話。

2 是 1：ちゅうしゃじょう（駐車場）是停車場，停車是 車をとめる。賣車、修車、洗車都不是停車場的功能。

3 是 3：～にくい ＝ 不容易做，等於 ～やすくない。1 意思相反；2 講的是用得少，不是難用；4 是已經用不了。

4 是 4：ゆうべ 是昨晚。けさ 是今早，おととい 是前天。

考試熱身：問題5 用法（詞語用得對不對）

N4 才有的題型。每題給一個詞，四句之中只有一句用得對，選出號碼。

  1. るす
    1. るすの日は、家いえでゆっくり過すごします。
    2. すみません、この席せきはるすですか。
    3. きのう友だちの家いえへ行きましたが、るすでした。
    4. 先生はきょう、るすで学校に来ません。
  2. しんせつ
    1. この料理りょうりはとてもしんせつです。
    2. 駅でしんせつな人が道を教おしえてくれました。
    3. きょうはしんせつな天気てんきですね。
    4. このパソコンは、とてもしんせつです。
  3. 片付かたづける
    1. 道で友だちを片付かたづけました。
    2. すみません、この漢字かんじの読よみ方かたを片付かたづけてください。
    3. 来週、大阪おおさかに片付かたづけます。
    4. 部屋へやを片付かたづけたら、広ひろくなりました。
  4. 間まに合あう
    1. 走はしったら、電車に間まに合あいました。
    2. この服ふくは、わたしによく間まに合あいます。
    3. 駅で、友だちに間まに合あいました。
    4. 二つの答こたえが間まに合あいません。
答案

做法：每一句把那個詞換成你心中的中文，讀得通的才對。

1 是 3：るす（留守）是去找人或打電話時，對方不在家。1 應該是 休やすみ，2 應該是 空あいています，4 也是 休やすみ。中文「留守」是留下看家，意思剛好相反，小心。

2 是 2：しんせつ（親切）形容人待人好。菜、天氣、電腦都不會「親切」：1 應該是 おいしい，3 是 いい，4 是 使つかいやすい 或 便利べんり。

3 是 4：片付かたづける 是收拾東西。1 不能「收拾」朋友；2 應該是 教おしえて；3 搬家是 引ひっ越こします。

4 是 1：間まに合あう 是趕得及。2 衣服合身好看是 似合にあいます，3 碰到朋友是 会あいました，4 答案一致是 合あいません。字面都有「合」，就是陷阱所在。

言語知識（文法）・讀解

考試熱身：問題1 文法形式の判断（選文法形式）

（　）裏面放哪一個最合適？

  1. 漢字かんじが難むずかしいです。わたしはこの漢字かんじが（　）。
  2. 子どものとき、わたしは母に嫌きらいな野菜やさいを（　）。
  3. 駅に（　）、電話してください。
  4. A：熱ねつがあるんです。
    B：じゃ、きょうは早はやく（　）ほうがいいですよ。
  5. 社長しゃちょうは、何時に会社に（　）か。
  6. 田中たなかさんがわたしに辞書じしょを貸かして（　）。
答案

1 わたしはこの漢字かんじが読よめません。 「漢字が」用 が，後面要配可能形。読みません 是不讀（要用 を）；読まれません 是被動；読ませません 是不讓人讀。

2 わたしは母に嫌きらいな野菜やさいを食たべさせられました。 「被媽媽逼著吃」，使役被動。食べさせました 變成我逼媽媽吃；くれました 的主語不能是「わたし」；たがりました 只用於第三者。

3 駅についたら、電話してください。 前半句是「到了車站之後」，後半句是請求，用 たら。と 是自然結果，後面不能接請求；ば 前面是「到達」這類動作時，後面也不能接請求；なら 是「如果你打算去車站的話」，時間次序不對。

4 早はやくかえったほうがいいですよ。 給建議的 ～ほうがいい 接た形。て形、意向形、命令形都接不上 ほう。

5 社長しゃちょうは、何時に会社にいらっしゃいますか。 講社長的動作要用尊敬語 いらっしゃる。まいる、おる、いたす 都是謙讓語，用在自己身上，用在社長身上等於把他降級。

6 田中たなかさんがわたしに辞書じしょを貸かしてくれました。 別人為我做事，主語是對方，用 くれる。あげる、さしあげる 是由我方給出去；もらう 的主語要是「わたし」，助詞也要改成「田中さんに」。

考試熱身：問題2 文の組み立て（★ 排句）

把四個部分排成一句通順的句子，★ 的位置放的是哪一個？選出號碼。

  1. わたしは　＿＿　＿＿　★　＿＿　があります。
    1 こと　2 行った　3 北海道ほっかいどう　4 へ
  2. この薬くすりを　＿＿　＿＿　★　＿＿　よ。
    1 元気げんき　2 なります　3 飲めば　4 に
  3. 大切たいせつな　＿＿　＿＿　★　＿＿　しまいました。
    1 を　2 友だちの　3 なくして　4 本
  4. 夏休なつやすみは　＿＿　＿＿　★　＿＿　思おもっています。
    1 と　2 国　3 帰かえろう　4 へ
答案

1 是 2：わたしは　北海道ほっかいどう　へ　行った　こと　があります。 ～たことがある，講經驗，第 11 章。

2 是 4：この薬くすりを　飲めば　元気げんき　に　なります　よ。 ば 條件句，加上「元気になる」，第 14 章。

3 是 1：大切たいせつな　友だちの　本　を　なくして　しまいました。 ～てしまう 表示遺憾，第 16 章。「を」必定緊接名詞「本」。

4 是 3：夏休なつやすみは　国　へ　帰かえろう　と　思おもっています。 意向形加 と思っています，講打算，第 15 章。

考試熱身：問題3 文章の文法（文章填空）

嘉欣寫了一篇作文。（1）至（4）放哪一個最合適？

カフェのアルバイト

わたしは下北沢しもきたざわのカフェでアルバイトをしています。はじめは、敬語けいごがぜんぜん（1）。

ある日、お客きゃくさんに「何を食べますか」と聞いて、店長てんちょうに注意ちゅうい（2）。「何を召めし上あがりますか」が正ただしい言い方かたです。

それから、店長てんちょうは毎日少しずつ敬語けいごを教おしえて（3）。おかげで、今は敬語けいごが少し話せるようになりました。

来年は、日本の会社で（4）と思おもっています。

答案

（1）話せませんでした：「敬語が」用 が，配可能形，意思是「完全不會說」。後文「今は少し話せるようになりました」也是可能形，前後呼應。其餘三個是一般否定、被動、使役。

（2）されました：我問錯了話，被店長提醒，用被動 注意ちゅういされる。しました 變成我提醒店長；させました 是叫店長提醒；してくれました 文法上說得通，但「店長に」要改成「店長が」。

（3）くれました：店長為我做事，主語是店長，用 くれる。もらいました 要主語是「わたし」，句子要改成「店長に教えてもらいました」。

（4）はたらこう：意向形加 と思っています，表示打算。はたらいた 是過去，はたらけ 是命令形，はたらかれる 是被動，都不是自己的打算。

考試熱身：問題4 内容理解（短文）

讀下面三篇短文，回答問題。

  1. 嘉欣カーヤンさんへ
    きのうはケーキをありがとう。とてもおいしかったです。
    今日の午後、電気の会社の人が来ます。わたしは三時までアルバイトです。もし人が来たら、二階かいの台所だいどころに案内あんないしてあげてください。かぎは玄関げんかんの机つくえの上に置おいてあります。
    田中たなか

    電気の会社の人が来たら、嘉欣カーヤンさんは何をしますか。

    1. 田中たなかさんに電話をかけます。
    2. かぎを田中たなかさんに持もっていきます。
    3. その人を台所だいどころに案内あんないします。
    4. その人に三時まで待まってもらいます。

  2. 図書館としょかんからのお知しらせ
    本は一人十冊さつまで、二週間借かりることができます。CD と DVD は一人三枚まいまで、一週間です。
    来月から、毎週月曜日げつようびと火曜日かようびは休みになります。

    CD は何枚まい、どのぐらい借かりることができますか。

    1. 三枚まい、一週間
    2. 三枚まい、二週間
    3. 十枚まい、一週間
    4. 十枚まい、二週間

  3. わたしは毎朝まいあさコーヒーを飲みます。前は、一日に五杯ごはいぐらい飲んでいました。でも、医者いしゃに「飲みすぎないほうがいいですよ」と言われました。それで、朝あさと昼ひるに一杯いっぱいずつ飲むことにしました。夜よるはお茶ちゃを飲んでいます。

    この人は今、一日に何杯なんばいコーヒーを飲みますか。

    1. 一杯いっぱい
    2. 二杯にはい
    3. 三杯さんばい
    4. 五杯ごはい
答案

1 是 3：「もし人が来たら、二階かいの台所だいどころに案内あんないしてあげてください」。鎖匙已經放在桌上，不用拿給田中（2）；便條沒有叫她打電話（1），也沒有叫對方等（4）。

2 是 1：CD 和 DVD 每人三張，借一星期。十冊、兩星期是書的規則，選項把兩組數字交叉配對，專騙看得快的人。

3 是 2：早上和中午各一杯，ずつ 是「各」。五杯是以前的習慣；晚上喝的是茶，不是咖啡，所以不是三杯。

考試熱身：問題5 内容理解（中文）

讀下面的作文，回答問題。

わたしは台湾たいわんのエンジニアです。先月、東京とうきょうの会社から大阪おおさかの会社に移うつりました。

大阪おおさかに来て、言葉ことばにびっくりしました。会社の人たちは、関西弁かんさいべんで話します。はじめは、みんなの話がよくわかりませんでした。

ある日、佐藤さとうさんに「この資料しりょう、なおしといて」と言われました。わたしは「なおす」は「直なおす」だと思おもって、資料しりょうを全部ぜんぶ書き直なおしてしまいました。でも、関西かんさいでは「なおす」には「片付かたづける」という意味いみもあるんです。佐藤さとうさんは笑わらって、「ごめんなさい。たなに片付かたづけておいてください、という意味いみでした」と教おしえてくれました。

今は、関西弁かんさいべんが少しわかるようになりました。来月、佐藤さとうさんたちと飲みに行く予定よていです。わたしも関西弁かんさいべんで話してみようと思おもっています。

子軒しけん

  1. 子軒しけんさんは、どうして資料しりょうを全部ぜんぶ書き直なおしましたか。
    1. 「なおす」の意味いみをまちがえたから。
    2. 資料しりょうにまちがいがたくさんあったから。
    3. 佐藤さとうさんに「書き直なおしてください」と頼たのまれたから。
    4. 関西弁かんさいべんで書きたかったから。
  2. 佐藤さとうさんの「なおしといて」は、どんな意味いみでしたか。
    1. 資料しりょうを書き直なおしておいてください。
    2. 資料しりょうを片付かたづけておいてください。
    3. 資料しりょうを読んでおいてください。
    4. 資料しりょうをコピーしておいてください。
  3. 子軒しけんさんは来月、何をするつもりですか。
    1. 東京とうきょうの会社に戻もどります。
    2. 佐藤さとうさんに中国語ちゅうごくごを教おしえます。
    3. 資料しりょうを全部ぜんぶ書き直なおします。
    4. 佐藤さとうさんたちと飲みに行って、関西弁かんさいべんで話してみます。
答案

1 是 1：他以為「なおす」是「修改」，其實佐藤要的是「收好」。資料本身沒有錯（2）；佐藤說的是「なおしといて」，不是「請重寫」（3）。

2 是 2：文中說關西的「なおす」也有「片付かたづける」的意思，佐藤也親口解釋了。なおしといて 是 なおしておいて 的口語縮約，～ておいて 變成 ～といて，第 16 章的 ておく。

3 是 4：「飲みに行く予定よていです」加上「関西弁かんさいべんで話してみようと思おもっています」，兩句合起來就是 4。1、2 文中沒有提；3 是已經做過的事。

考試熱身：問題3 発話表現（這時候說甚麼）

先看情境（真試是一幅圖，箭頭指著說話的人），再按 ▶ 聽三個說法，選出最合適的一個。

  1. 情境：你在餐廳，想請店員再給你一杯水。
  2. 情境：上司下班，比你先離開公司。
  3. 情境：你想請朋友幫你拍照。
  4. 情境：你打電話到別的公司，先報上自己的名字。
答案和文字稿

1 是 1：1 すみません、お水をいただけますか。2 すみません、お水をさしあげましょうか。3 すみません、お水を飲のんでもらいます。 向人要東西，用 いただけますか（いただく 的可能形）。2 是「我給您水吧」，方向反了；3 是「我要叫你喝水」。

2 是 2：1 いってらっしゃい。2 おつかれさまでした。3 おさきにしつれいします。 對下班的人說 おつかれさまでした。おさきにしつれいします 是先走的人自己說的，這裏先走的是上司；いってらっしゃい 是送人出門、對方還會回來時說的。

3 是 3：1 写真しゃしんをとってあげようか。2 写真しゃしんをとってもいい？　3 ちょっと写真しゃしんをとってくれない？ 請人為你做事：～てくれない？ 1 是「我幫你拍吧」，2 是「我可以拍嗎」，兩個都是你自己拍。

4 是 2：1 わたくし、みどり電気でんきの林はやしさんでございます。2 わたくし、みどり電気でんきの林はやしと申もうします。3 わたくし、みどり電気でんきの林はやしとおっしゃいます。 自稱用謙讓語 申もうします。自己名字後面不加 さん；おっしゃる 是尊敬語，不能用在自己身上。
