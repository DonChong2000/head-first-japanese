第 24 章

N3 聽解：日常會話

課本的日語和耳朵聽到的日語，是兩種東西。這一章教你的耳朵。

共享屋客廳，田中さん和嘉欣在看日劇字幕じまくがあれば、わかるんですけど……音おとだけだと、全然ぜんぜん聞き取とれません。

田中さんドラマの人、速はやいよね。今、「何してんの」って言ったでしょ？

嘉欣「しんの」……？

田中さん「何をしているの」を縮ちぢめて、「何してんの」。

嘉欣聞こえた音おとと、教科書きょうかしょの日本語が、ぜんぜん違ちがいます。

田中さん日本人は、教科書きょうかしょみたいには話さないからね。耳みみも、練習れんしゅうしないと慣なれないよ。

嘉欣，心想我讀得懂，卻聽不懂。原來讀和聽，是兩個獨立的技能。

你在第 11 章學過普通形，第 16 章學過 ～てしまう 的口語 ちゃう。可是真正的對話，縮短、省略、含糊、說到一半就停，比課本的例句多得多。這一章先弄清楚 N3 聽解考甚麼，再學最影響聽力的「縮約形」，最後實戰。

所有聽解練習的聲音，來自你瀏覽器的日語語音。它的聲音只有一把，男女都用同一把，所以每段錄音裏會讀出「男」「女」，讓你知道是誰在說話。語速偏慢，比真試更容易，需要練習真速時，請看第 33 章。

規則 1：N3 聽解考甚麼

日本國際交流基金和日本國際教育支援協會的官方網站（jlpt.jp）說明，N3 的聽解時間是 40 分鐘，題型包括課題理解、ポイント理解、発話表現、即時応答；官方網站也說明，時間可能因錄音長度略有不同。歷年的 N3 樣本題中，通常還有一個「概要理解」（聽完一段話，說出大意）。每個題型的出題方式不同，最新資料以 jlpt.jp 為準。

題型考甚麼策略
課題理解
（Task-based）		聽完對話，問「接下來要先做甚麼」先讀選項，圈出動作；留意 まず、その前に、やっぱり、じゃ 等改變計劃的詞
ポイント理解
（Key points）		聽重點：原因、地點、時間、感想先聽題目，知道要找甚麼；答案多數在 でも、けど 後面
概要理解
（General outline）		聽一段話，抓說話者的想法不要抓細節；聽「意見」，最後幾句通常有結論
発話表現
（Verbal expressions）		在某個情景下，應該說甚麼想「這是誰對誰說」，再選；敬語的方向在這裏考
即時応答
（Quick response）		聽一句話，選最合適的回應抓疑問詞和句型，再排除不相關的；選項很短，要快

先記住一個全部題型都通用的原則：聽到的內容會被改寫。錄音說 電話します，選項寫 連絡れんらくする；錄音說 ペットボトルの水を取とってください，選項寫 飲み物ものを渡わたす。考的是理解，不是「聽到甚麼字，就選有那個字的選項」。出現了完全相同的字的選項，有時反而是陷阱。

規則 2：縮約形：耳朵聽到的，不是紙上寫的

日常會話裏，語法上的長形式會縮短。你不需要學會說，但一定要認得出來：

書面形口語縮約例子（按一下聽）
～ている～てる何してるの？（何をしているの）
～ていく～てく傘かさ、持もってくね。（持もっていくね）
～ておく～とく見とくね。（見ておくね）
～てしまう～ちゃう、～ちゃったもう食べちゃった。
～では／～ては～じゃそれじゃ、困こまるよ。
～なければ（ならない）～なきゃもう行かなきゃ。
～なくては～なくちゃ早はやく寝ねなくちゃ。
わからないわかんない全然ぜんぜんわかんない。
～のだ／～んです～んどうしたの？、行くんだ。
～という～っていう、～って田中たなかさんって人、雨が降ふるって。
ところとこ今、帰かえったとこ。
それはそりゃそりゃ、大変たいへんだね。
食べられる食べれる（ら抜き）これ、食べれる？

幾個要點：

  • ちゃう、とく、なきゃ 都是在「て」「で」前面脫掉一個音，聽起來是新詞，其實是舊朋友。
  • 句尾的 の 和 ん：どうしたの？（發生甚麼事？）句尾上升的 の 是疑問，不是「的」。
  • って 有三個身分：引用（～って言った）、傳聞（雨が降ふるって）、話題（田中たなかさんって人）。
  • 用 ら抜ぬき 的 食べれる，在第 12 章說過，口語常見，考試的書面題不當作正確答案，但聽解裏一定要聽得懂。

你可以把這些縮約形想成「語音的壓縮檔」：解壓的方法就是在腦裏還原。聽到 わかんない，還原成 わからない；聽到 なきゃ，還原成 なければならない。

中文腦：粵語的縮讀，你本來就會

粵語一樣有縮讀，只是你沒有留意。「點解」讀成 dim2 gaai2，語速一快變成 dim2-gaai2；「冇啦」的 mou5 laa1；「唔該」讀成 m4 goi1，快的時候像 mgoi1。普通話也有：「不知道」讀成 bù-zhī-dào，口語常常是 bùzhídào；「這個」常讀成 zhèi ge。

所以縮約形對你來說，只是同一個道理換了語言。日語的差別在於：縮讀的規律比較整齊（て 的前後變成 ちゃ、とく），學一次，聽得出許多句子。

規則 3：聽的技巧：不要每個字都追

N3 聽解的錄音比真實對話慢，但比課堂慢速錄音快得多。每個字都追，肯定追不上。更好的做法是：

  1. 聽「骨架」。名詞、動詞、數字，抓到這幾個，再用文法詞（でも、から、けど）判斷關係。
  2. 聽轉折。課題理解的 やっぱり、じゃ、それなら，常常是「改了計劃」的信號：やっぱり、電車で行くことにします，答案是電車，不是前面討論的巴士。
  3. 聽委婉的拒絕。ちょっと……、うーん、どうかな、考かんがえておきます，都是「不」的意思。即時応答裏，はい、いいですよ 配上 ちょっと…… 的語氣，是拒絕。
  4. 聽填充詞。えーと、あのう、まあ、なんか 都是「想一想」的聲音，沒有資訊，可以直接略過，等它後面的內容。
  5. 先看選項。有印出選項的題型（課題理解），先看一遍：每個選項是甚麼動作？聽的時候，看哪個動作出現。沒有印選項的（即時応答），先抓疑問詞：いつ、どこ、誰だれ、どうして。

還有一個容易被忽略的地方：同音詞靠音調分辨。日語有很多同音不同調的詞，N3 的聽解偶爾會用到：

詞意思音調（相對高低）
はし（橋）／はし（箸）橋／筷子橋：低高（は↗し）；筷子：高低（は↘し）
あめ（雨）／あめ（飴）雨／糖果雨：高低；糖果：低高

這些對照以東京的標準音調為準，關西的音調常常不同，有些剛好相反。第 1 章你見過高低音調，N3 還沒有要求會寫音調，但聽到時知道「這是兩個詞」就夠。

規則 4：聽解的場景和常見詞

N3 聽解的情景，其實相當固定：車站、商店、公司、家、醫院、學校。每個場景有一批高頻詞。上課前先把這些詞放進腦裏，聽的時候就少用一半力氣：

場景常見的詞典型的事
車站ホーム、乗のり換かえる、切符きっぷ、精算せいさん、急行きゅうこう、普通ふつう、遅おそれる問路、補票、換車
商店サイズ、在庫ざいこ、返品へんぴん、割引わりびき、レジ、袋ふくろ找不同尺碼、退貨、結帳
公司会議かいぎ、資料しりょう、締しめ切きり、出張しゅっちょう、予約よやく、連絡れんらく分配工作、改時間、準備會議
家掃除そうじ、洗濯せんたく、ごみ、家賃やちん、引ひっ越こし家務、搬家、和室友商量
醫院、藥房予約よやく、診察しんさつ、薬くすり、熱ねつ、症状しょうじょう問症狀、預約、領藥
學校宿題しゅくだい、試験しけん、授業じゅぎょう、先生、課題かだい交功課、補考、問老師

每個場景，最常見的「變化」也很固定：時間改了、地點改了、人數改了、東西換了。所以聽到一個地點或數字，記下來，再看下一句會不會被改掉。

規則 5：對話裏的「確認」和「轉折」

N3 的對話，常有說話人重複對方的話，來確認。這時候不是說錯，是在確認：

  • 三時ですね。（是三點對吧？）：重複剛才聽到的資料，後面常是肯定。
  • つまり、～ということですか。（也就是說，是……的意思嗎？）：整理成自己的話，後面是「對」或者「不對，是……」。
  • え、～なの？（咦，是……嗎？）：驚訝，說明剛才的資料出乎意料，後面常有解釋。

轉折的信號詞，在課題理解和ポイント理解裏，是最多答案的地方：

聽到意思接下來
でも、けど、ただ但是原因或條件，常是答案
やっぱり還是……（改變主意）以最後說的為準
じゃ、それなら那麼做決定
まず、それから、最後さいごに先、再、最後順序，課題理解的核心
実じつは其實真正的原因

把這幾個詞當成信號燈：聽到它們，就是要注意答案的時候。

練習：N3 聽解模擬

做法跟 JLPT 一樣：只聽一次。按 ▶ 聽完就作答，不要重播。答完才打開答案，看文字稿，再自己讀一遍，最好大聲讀到跟得上錄音的速度。錄音會先交代情景和問題，再播對話。

考試熱身：N3 聽解 問題1 課題理解

先看選項，再按 ▶。留意「まず」「その前に」「やっぱり」。

    1. 隣となりのホームに行く。
    2. 精算機せいさんきでお金を払はらう。
    3. 駅員えきいんに切符きっぷをもらう。
    4. 新宿しんじゅく行きの電車に乗のる。
    1. ペットボトルのふたとラベルを取とる。
    2. 雑誌ざっしを出す。
    3. ペットボトルを洗あらう。
    4. 燃もえるごみを出す。
    1. グラフを作つくる。
    2. 会議室かいぎしつを予約よやくする。
    3. 木村きむらさんに連絡れんらくする。
    4. 資料しりょうを作つくり直なおす。
答案和文字稿

1 是 2。她說 その前に、切符きっぷを買わなくちゃ，所以先要處理車票：站員指示去精算機補差額，然後才去隔壁月台搭車。なくちゃ 是 なくては 的縮約形。

女：すみません、新宿しんじゅくに行きたいんですが、この電車でいいですか。
男：いいえ、この電車は新宿しんじゅくに行きません。隣となりのホームの電車に乗のってください。
女：隣となりですね。あ、その前に、切符きっぷを買わなくちゃ。この切符きっぷは東京とうきょうまでなんです。
男：それなら、あそこの精算機せいさんきで、差額さがくを払はらえば大丈夫だいじょうぶですよ。
女：わかりました。ありがとうございます。

2 是 1。取とって、洗あらってから出してね 是順序：先取下蓋子和標籤，再洗，再丟。問的是「まず」，所以是第一步。雜誌是下星期，所以今天不丟。

男：あした、ごみの日だよ。
女：燃もえるごみですか。
男：ううん、あしたはプラスチック。ペットボトルとか、食べ物ものの容器ようきとか。
女：ペットボトルは、ふたとラベルを取とらなきゃいけませんか。
男：うん、取とって、水で洗あらってから出してね。
女：わかりました。この雑誌ざっしも出していいですか。
男：雑誌ざっしは資源しげんごみの日、来週らいしゅうだよ。
女：じゃ、今日はペットボトルだけですね。

3 是 3。グラフは木村きむらさんが作つくる，所以不用自己做（1 錯）；會議室已經訂了（2 錯）；資料作了三分之二，不用重做（4 錯）。她要先 連絡れんらくして，再送資料，所以「まず」是聯絡。～ておく 在這裏是「先做好」。

男：来週らいしゅうの会議かいぎの資料しりょう、どこまでできた？
女：全体ぜんたいの三分の二ぐらいです。グラフがまだで。
男：グラフは、木村きむらさんが作つくることになってるよ。
女：あ、そうなんですか。じゃ、木村きむらさんに連絡れんらくして、データを送おくっておきます。
男：うん。それと、会議室かいぎしつの予約よやくは？
女：それはもうしてあります。
男：じゃ、お願ねがいね。

考試熱身：N3 聽解 問題2 ポイント理解

錄音先讀出問題。先聽問題，才知道要抓甚麼。

    1. 寝坊ねぼうしたから
    2. 電車が遅おそれたから
    3. 財布さいふを探さがしたから
    4. 交番こうばんで道を聞いたから
    1. 駅から五分で、八万円の部屋へや
    2. 駅から十五分で、六万円の部屋へや
    3. 駅から十分で、七万円の部屋へや
    4. まだ決きめていない。
    1. カレー
    2. ハンバーグ
    3. サラダセット
    4. ラーメン
答案和文字稿

1 是 3。他說自己睡過頭了，但 電車は、ちゃんと間に合あった，所以睡過頭不是遲到的原因。真正的原因在 でも 後面：財布さいふを落おとしたことに気づいて、探さがしに戻もどった。留意 寝ねちゃって（寝ねてしまって）是縮約形。

女：遅おそいよ、三十分も。
男：ごめん。目覚めざまし時計とけいをかけたんだけど、止とめて、また寝ねちゃって。
女：それで、電車は？
男：電車は、ちゃんと間に合あったんだ。でも、駅から走はしってる途中とちゅうで、財布さいふを落おとしたことに気づいて、探さがしに戻もどったんだよ。
女：えっ、見つかった？
男：うん、交番こうばんにあった。

2 是 2。她嫌八萬圓太貴，又不喜歡舊的，最後說 二つ目めにします。聽到數字時，把「房間編號、距離、價錢」記成三組，才不會混。

男：一つ目めは、駅から五分で、家賃やちんは八万円です。二つ目めは、駅から十五分ですが、家賃やちんは六万円で、広ひろいです。三つ目めは、駅から十分で七万円、でも古いです。
女：駅から近ちかいほうがいいけど、八万円はちょっと高いなあ。
男：二つ目めは少し遠とおいですが、自転車じてんしゃを使つかえば大丈夫だいじょうぶですよ。
女：そうですね。……三つ目めは、古いのがちょっと。じゃ、二つ目めにします。

3 是 2。題目問的是「女の人のおすすめ」，她說 わたしのおすすめは、ハンバーグ。男的最後選了沙律（3），那是他的決定，不是她的推薦。聽解常這樣：題目問的人，和最後做決定的人，不是同一個。～んだって 是 ～のだそうだ 的口語（傳聞）。

男：このお店みせ、何がおいしいの？
女：カレーも人気だけど、わたしのおすすめは、ハンバーグ。毎日、店みせで手て作つくりしているんだって。
男：へえ。でも、肉にくは今日はちょっと。
女：じゃ、サラダセットは？野菜やさいがたっぷりだよ。
男：じゃ、それにする。

考試熱身：N3 聽解 問題3 概要理解

沒有印出來的選項，也沒有圖。先聽整段話，然後聽三個選項，選出跟話的主旨最接近的。不要執著於細節，抓「他想說甚麼」。

答案和文字稿

1 是 1。一開頭是現象（無人收銀店變多），中間有 便利べんりですが，後面是 使つかいにくいという声こえもあります：兩面都說。結論是「便利，但不是每個人都用得來」。2 和 3 的內容，文章裏完全沒有。

最近さいきん、駅やデパートで、レジのない店みせが増ふえています。お客きゃくさんは、商品しょうひんをかばんに入れて、そのまま出ていくだけです。お金は、アプリで自動的じどうてきに払はらわれます。便利べんりですが、スマホを持もっていない人や、お年寄としよりには、使つかいにくいという声こえもあります。店みせの人は、「誰だれでも使つかえる店みせにしたい」と話しています。

2 是 2。最後兩句是結論：観光地かんこうちより、そういう場所ばしょのほうが、心こころに残のこっています。前面提到的有名寺院，他是「見たけれどゆっくり見られなかった」，所以不是最好的（1 錯）；文中沒有提到拍照（3 錯）。留意 ぼんやりしていました 是「發呆、放空」，不是壞事。

先週せんしゅう、友達ともだちと京都きょうとに行きました。有名ゆうめいなお寺てらをいくつか見ましたが、人がとても多くて、ゆっくり見られませんでした。それで、三日目めは、地図ちずに載のっていない小さな道を歩あるいてみました。すると、静しずかな庭にわのあるお寺てらを見つけて、そこで一時間もぼんやりしていました。観光地かんこうちより、そういう場所ばしょのほうが、心こころに残のこっています。

考試熱身：N3 聽解 問題4 発話表現

先聽情景，再聽三個說法，選最合適的一個。

答案和文字稿

1 是 1：引ひっ越こし、手て伝つたおうか。（要不要我幫你搬家？）意向形加 か，是提出幫忙。2 是請對方幫忙，3 是已經得到了幫忙。

2 是 1：これより大きいのは、ありませんか。（有比這個大的嗎？）の 是第 19 章的「那一個」。2 是「這個會變大嗎」，3 是「這個大嗎」，問的是別的事。

3 是 1：では、失礼しつれいいたします。，結束電話的標準說法（第 18、22 章）。2 的 お邪魔じゃまします 是進別人家時說的，3 是店員歡迎客人。

考試熱身：N3 聽解 問題5 即時応答

沒有圖，也沒有印出來的選項。按 ▶ 聽一句話和三個回應，選出最合適的回應。

答案和文字稿

1 是 1：この仕事しごと、今日中にできそう？／はい、できそうです。問「做得完嗎？」，答「看樣子做得完」，樣態。2 是傳聞，3 是過去的傳聞，都說不通。第 20 章。

2 是 1：明日あしたの会議かいぎ、出なきゃいけないの？／ううん、出なくてもいいよ。なきゃいけない 是 なければならない 的縮約形。問「一定要出席嗎」，答「不用」。2 是「正在出席」，3 是「早知道就出席了」，都不是答案。

3 是 1：この荷物にもつ、重おもそうですね。持もちましょうか。／ありがとうございます。お願ねがいします。對方問「要我幫你拿嗎」，接受就說 お願ねがいします。2 把 重おもそう（看起來重）答成傳聞 重おもいそうです，3 是拒絕，但沒有禮貌（只說 持もちません，意思是「我不拿」）。

4 是 1：どうして、昨日きのう来なかったんですか。／来るはずでしたが、急いそに熱ねつが出てしまって。第 21 章的 はずだった，後面接 が 說原因。2 的 来るはずがありません 是「不可能來」，語氣完全不對；3 是建議，沒有回答「為甚麼」。

5 是 1：社長は、いらっしゃいますか。／申もうし訳わけございません。社長は今、席せきを外しております。對外人說自己公司的社長，用謙讓語 II 的 おります（第 22 章）。2 的 いらっしゃいません 和 3 的 いらっしゃいます 都把自己人抬高了。

削尖你的鉛筆：影子跟讀（shadowing）

聽解進步最快的方法。打開上面任何一段文字稿，一邊按 ▶ 聽，一邊幾乎同步跟著唸，晚半拍也可以。不用求每個字都對，目標是跟上節奏和語調。錄下來，再跟原音比較。試試用課題理解第 3 題（公司裏的對話）：

グラフは、木村きむらさんが作つくることになってるよ。（按一下聽，然後跟著唸）

練習建議

每天十分鐘，只選一小段（三、四句）。第一天只聽，第二天看文字稿聽，第三天看文字稿跟讀，第四天不看文字稿跟讀。一星期之後，同一段會變成你「聽得很熟」的段落，這種熟悉感，是真試聽解需要的。

留意 なってる 是 なっている：聽不出來的 い，是日語聽解最常「漏掉」的音。

沒有蠢問題

聽解總是慢半拍，怎麼辦？
聽解不是越慢越好。N3 的聽解要在一次播放裏答題，所以必須學會「預測」：看選項，猜會說甚麼。同時要用上面的方法，不要追每個字。
聽不清楚的時候，要不要猜？
要猜，但是有根據地猜。先排除一定不可能的（例如方向反了的敬語、時態不對的），剩下的再憑印象選。沒有作答的題目一定得不到分，選一個至少還有機會。
為甚麼聽力練習用電腦語音，而不是真人？
瀏覽器語音沒辦法有真人的情感和停頓，所以它只能幫你練習「聽得清楚的日語」。要適應真人的語速和情感，請同時看日劇、聽 podcast、跟日本朋友說話。每星期至少一次真人，不要只靠機器。
縮約形，我也應該自己說嗎？
跟朋友之間可以，慢慢用。在面試和職場，用書面形，不要說 なきゃ、ちゃった。聽得懂是第一步，說的時候看場合。

重點整理

  • 據 jlpt.jp，N3 聽解 40 分鐘（可能略有不同）；題型有課題理解、ポイント理解、発話表現、即時応答，另有概要理解（以官方公布為準）。
  • 聽解會改寫：錄音和選項的用字常常不同，只抓同一個字，容易中陷阱。
  • 縮約形：てる（ている）、とく（ておく）、ちゃう（てしまう）、なきゃ（なければ）、じゃ（では）、わかんない、って（という、傳聞、話題）。
  • 課題理解：留意 まず、その前に、やっぱり、じゃ。
  • ポイント理解：答案常在 でも、けど 後面；題目問的是誰，就找誰的話。
  • 概要理解：聽結論，不要追細節。
  • 発話表現、即時応答：想「誰對誰說」，敬語方向在這裏考；ちょっと…… 是委婉的「不」。
  • 練習方法：影子跟讀，每天十分鐘；同時多接觸真人的日語。
