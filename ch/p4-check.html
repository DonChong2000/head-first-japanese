第四部分 自測

N2 自測：第四部分的期末考

書面句型、常體、擬態語、商務敬語、長文閱讀：跟 N3 一樣的格式，題目卻不再讓你靠運氣。

這份自測照足 JLPT N2 的題型和次序：文字・語彙六種、文法三種、讀解五種、聽解五種。題目以第 25 至 29 章為主，也會用到 N5 至 N3 學過的東西，共 62 題。N2 的題目比 N3 長，你會明顯感覺到：不是詞不認得，而是時間不夠。

怎樣做這份自測

  • 計時。真試的言語知識和讀解合共 105 分鐘，聽解 50 分鐘（jlpt.jp）。這份自測的題數比真試少，建議言語知識（文字・語彙、文法）和讀解合共用 60 至 70 分鐘，記下實際用的時間，下次重做時比較。
  • 不要偷看。做完一個方塊才按「檢查」，再打開答案。每個選項為甚麼錯，答案都有解釋。
  • 聽解只聽一次。按 ▶ 聽完就作答，不要重播。答完才打開答案看文字稿，再自己把文字稿讀出來。
  • 聽解由瀏覽器朗讀，男女同一把聲音，錄音裏會讀出「男」「女」標明誰在說話。真試的聽解多數有圖或表，這裏改用文字選項。
  • N2 以上的漢字都有振假名，較簡單的詞也常常有。文字・語彙問題 1 和問題 2 的題目句按了不會發聲，被考的詞沒有振假名；頂部的「ふりがな」開關只管可以按的日語，題目句裏的振假名不受影響。

做不完也不要緊，做到哪裏記到哪裏。

真試的計分方法：N2 滿分 180，分三科（言語知識 60、讀解 60、聽解 60）。合格要總分 90 分以上，而且每一科不能低於 19 分（資料來源：jlpt.jp）。考試的最新細則請看官方網站。

言語知識（文字・語彙）

考試熱身：問題1 漢字読み（漢字讀法）

劃了線的詞怎樣讀？選出正確的平假名。

  1. その点てんについては懸念がございます。
  2. 納期は注文ちゅうもんから二週間しゅうかんの予定よていです。
  3. ボランティアを募集している。
  4. たまには贅沢な時間じかんを過すごしたい。
答案

1 けねん：「懸」是 けん 或 け，這個詞讀 け，「念」讀 ねん。けんねん 把「懸」讀成 けん，是最常見的錯。第 28 章。

2 のうき：「納」是 のう，「期」是 き。のうぎ 錯在濁音。第 28 章。

3 ぼしゅう：「募」是 ぼ，短音。ぼうしゅう 多了一個長音。第 26 章的新聞稿。

4 ぜいたく：「贅」是 ぜい，「沢」是 たく。第 29 章最後一段。

考試熱身：問題2 表記（寫法）

劃了線的詞，用漢字應該怎樣寫？

  1. 新あたらしいサービスをけんとうしている。
  2. 信号しんごうのないおうだん歩道ほどうは危あぶない。
  3. 情報じょうほうをていきょうしていただき、ありがとうございます。
答案

1 検討：「検」是木字旁，不是「険」（耳字旁）也不是「験」（馬字旁）。第 26 章提醒過，日語的「検討」是「考慮」，跟中文「檢討」的意思不同。

2 横断：「横」是木字旁。「桟」是另一個字，「往」是彳字旁，都是形近字。

3 提供：「提」是提手旁，「供」是人字旁加「共」。「堤」是土字旁（堤防），不是這個字。

考試熱身：問題3 語形成（詞的組成）

N2 才有的題型。（　）裏放哪一個，可以跟前面或後面的詞組成一個詞？

  1. 会議かいぎの議事録ぎじろくを電子でんし（　）する。
  2. この仕事しごとは、危険きけん（　）が高たかい。
  3. 会議かいぎ（　）は、電話でんわに出でないでください。
  4. （　）完成かんせいの絵えを展覧会てんらんかいに出だす。
答案

1 電子化でんしか（電子化）：〜化か = 變成。〜的てき、〜式しき 不能配這個名詞作動詞。2 危険性きけんせい：〜性せい = 性質。危険感きけんかん 不成立。3 会議中かいぎちゅう：〜中ちゅう = 正在。這個 ちゅう 跟 〜中じゅう（一日中いちにちじゅう）要分清。4 未完成みかんせい：未み〜 = 還沒有。不完成ふかんせい 不是日語。中文有「未」，日語的 み 用法跟中文一致，這是漢字文化的便利。

考試熱身：問題4 文脈規定（按上文下理選詞）

（　）裏面放哪一個最合適？

  1. 大雪おおゆきのため、電車でんしゃは運転うんてんを（　）いる。
  2. 景気けいきの悪化あっかを（　）する声こえが広ひろがっている。
  3. カレンダーには、来月らいげつの予定よていが（　）詰つまっている。
  4. ただいま席せきを外はずしております。戻もどりましたら、（　）お電話でんわいたします。
  5. 調査ちょうさの結果けっかを（　）、方針ほうしんを決きめる。
答案

1 見合みあわせる：暫停、擱置，鐵路消息的常用詞（第 26 章）。見送みおくる 是「決定不做」，見直みなおす 是「重新檢討」，語氣跟「停駛」不合。

2 懸念けねん：擔憂。概念がいねん（概念）、観念かんねん、断念だんねん（放棄）形近，但意思不通。

3 ぎっしり：塞得滿滿的（第 27 章）。ずらり 是排成一列，不是「塞滿」。

4 折おり返かえし：之後回電，電話用語（第 28 章）。繰くり返かえし（重複）說不通。

5 踏ふまえて：根據、考慮到（第 26 章）。其餘三個都是「踏」開頭的動詞，但意思不合。

考試熱身：問題5 言い換え類義（意思相近的詞）

哪一個跟劃了線的詞意思最接近？選出號碼。

  1. 彼女かのじょはうっかり大切たいせつな書類しょるいを忘わすれてしまった。
    1. 注意ちゅういが足たりなくて
    2. わざと
    3. ひどく疲つかれて
    4. 何度なんども
  2. 会議かいぎはただちに始はじまった。
    1. すぐに
    2. 予定よていどおりに
    3. ゆっくりと
    4. 遅おくれて
  3. 今日きょうはやや寒さむい。
    1. 少すこし
    2. とても
    3. まったく
    4. ときどき
答案

1 是 1：うっかり ＝ 一時沒注意；わざと 相反。第 27 章。2 是 1：ただちに ＝ 立刻，書面詞。第 26 章。3 是 1：やや ＝ 有點，書面詞，對應口語的 ちょっと。第 26 章。

考試熱身：問題6 用法（詞語用得對不對）

每題給一個詞，四句之中只有一句用得對，選出號碼。

  1. さっぱり
    1. 説明せつめいを聞きいても、さっぱり意味いみが分わからない。
    2. 今日きょうは、さっぱり忙いそがしい。
    3. 空そらがさっぱり晴はれた。
    4. 昨日きのうは、さっぱり食たべすぎた。
  2. 検討けんとう
    1. 間違まちがいを検討けんとうして、先生せんせいに謝あやまった。
    2. 来月らいげつの旅行先りょこうさきを検討けんとうしている。
    3. 風邪かぜの検討けんとうをして、会社かいしゃを休やすんだ。
    4. 毎日まいにちの検討けんとうを、日記にっきに書かいている。
  3. ぎりぎり
    1. 電車でんしゃに、ぎりぎり間まに合あった。
    2. 雨あめがぎりぎり降ふっている。
    3. 彼かれは、ぎりぎり優やさしい人ひとだ。
    4. この靴くつは、ぎりぎり軽かるい。
答案

做法：把詞換成你心中的意思，讀得通的才對。

1 是 1：さっぱり 後面接否定，意思是「完全不」（第 27 章）。2、3、4 的 さっぱり 都不能接肯定句，分別應該是 とても、すっきり、たくさん 或 つい。

2 是 2：検討けんとう = 考慮。1 用了中文「檢討」（反省）的意思，不成立；3 和 4 不是「研究、考慮」的對象。第 26 章的中文腦。

3 是 1：ぎりぎり = 剛好趕上，多與時間、數量的極限搭配。2、3、4 的詞都不是極限狀態。第 27 章。

考試熱身：問題7 文法形式の判断（選文法形式）

（　）裏面放哪一個最合適？

  1. 市しの発表はっぴょう（　）、来月らいげつから料金りょうきんが上あがる。
  2. 彼かれは忙いそがしい（　）、毎日まいにちジムに通かよっている。
  3. 新あたらしい工場こうじょうの建設けんせつ（　）、住民じゅうみんの意見いけんが分わかれている。
  4. 台風たいふうの接近せっきん（　）、運動会うんどうかいは中止ちゅうしになった。
  5. 上司じょうしの命令めいれいなので、行いか（　）。
  6. この薬くすりは子こどもに限かぎ（　）、大人おとなにも効果こうかがある。
  7. （客きゃくに）「ご注文ちゅうもんの品しなは、明日あしたまでに（　）。」
  8. 優勝ゆうしょう（　）、決勝けっしょうにも進すすめなかった。
答案

1 によると：傳聞的來源，「根據市政府的發表」。第 26 章。に対たいして 要有對象或對比。

2 にもかかわらず：「儘管很忙，仍然每天去健身房」，名詞性的形容詞 忙いそがしい 直接接。に応おうじて 是配合調整，不通。第 25 章。

3 をめぐって：圍繞著工廠建設意見分歧，爭論的對象。に基もとづいて 是依據，不是爭論。第 25 章。

4 に伴ともない：隨著颱風接近而中止，新聞常用。について 是「關於」，不能表示因果。第 26 章。

5 ざるを得えない：「上司的命令」＝外在壓力，所以「不得不去」。行いかかねない 形狀不通；行いかわけがない 也不通。第 25 章。

6 らず：〜に限かぎらず，不限於。第 25 章。

7 お届とどけいたします：主語是我，謙讓語。お届とどけになります 是尊敬語，用在客人身上。第 28 章。

8 どころか：期待優勝，結果決賽也進不了，與期待相反。ばかりか、のみならず 是遞進，前半必須是好事再加好事。第 25 章。

考試熱身：問題8 文の組み立て（★ 排句）

把四個部分排成通順的句子，★ 的位置放的是哪一個？選出號碼。

  1. 彼かれの冗談じょうだんを聞きいて、　＿＿　＿＿　★　＿＿　いられなかった。
    1 笑わらわ　2 ずには　3 思おもわず　4 おもしろくて
  2. 市しは、　＿＿　＿＿　★　＿＿　実施じっしするかどうかを決きめる方針ほうしんだ。
    1 結果けっかを　2 踏ふまえて　3 本格ほんかく　4 半年間はんとしかんの
  3. 　＿＿　＿＿　★　＿＿　いただけますでしょうか。
    1 添付てんぷの　2 資料しりょうを　3 ご確認かくにん　4 お忙いそがしいところ恐縮きょうしゅくですが
答案

1 是 1：彼かれの冗談じょうだんを聞きいて、おもしろくて思おもわず笑わらわずにはいられなかった。 次序是 4 3 1 2，★ 是 笑わらわ。〜ずにはいられない 的前面接ない形去掉ない，第 25 章。

2 是 2：半年間はんとしかんの結果けっかを踏ふまえて本格ほんかく実施じっしするかどうかを決きめる。次序是 4 1 2 3，★ 是 踏ふまえて。第 26 章的新聞句型。

3 是 2：お忙いそがしいところ恐縮きょうしゅくですが、添付てんぷの資料しりょうをご確認かくにんいただけますでしょうか。 次序是 4 1 2 3，★ 是 資料しりょうを。「ご確認」前面必須是「を」，所以「資料を」緊接其前。第 28 章。

考試熱身：問題9 文章の文法（文章填空）

（1）至（4）放哪一個最合適？

顔かおを合あわせて話はなすこと

SNSの普及ふきゅうにより、世界中せかいじゅうの人ひとと簡単かんたんに連絡れんらくが取とれるようになった。（1）、画面がめんの向むこうの相手あいての気持きもちは、なかなか伝つたわりにくい。メッセージの言葉ことばだけでは、冗談じょうだんのつもりが相手あいてを傷きずつけてしまうこともある。便利べんりな道具どうぐである（2）、使つかい方かたを間違まちがえれば、人間関係にんげんかんけいを壊こわしかねない。だからこそ、顔かおを合あわせて話はなす機会きかいを完全かんぜんに失うしなう（3）。もちろん、会あう時間じかんが取とれない人ひともいるだろう。そういう人ひとも、電話でんわやビデオ通話つうわ（4）、声こえや表情ひょうじょうで気持きもちを伝つたえる方法ほうほうはある。

答案

（1）しかし：前面說 SNS 讓聯絡變容易，後面說感情卻不易傳達，轉折。そのため 是因果，邏輯不通。

（2）ものの：「是便利的工具，可是用錯了……」，承認前半，轉向後半的警告。ばかりか 要接遞進，に対たいして 和 によって 與句意無關。

（3）わけにはいかない：「不能完全失去面對面說話的機會」，情理不許。かねない（可能會）接ます形，失うしなうかねない 形狀不對；ざるを得えない 接ない形，意思也不合。

（4）を通つうじて：透過電話和視像通話（媒介）。をめぐって 用於爭論，不合。

考試熱身：問題10 内容理解（短文）

讀下面的通知，回答問題。

お知しらせ

エレベーター点検てんけんのため、十一月二十一日（土ど）午前ごぜん九時じから正午しょうごまで、すべてのエレベーターを停止ていしします。ご不便ふべんをおかけしますが、ご協力きょうりょくをお願ねがいいたします。なお、重おもい荷物にもつの搬入はんにゅうなどでお急いそぎの方かたは、管理人室かんりにんしつ（内線ないせん一〇一）までご連絡れんらくください。

管理組合かんりくみあい
  1. このお知しらせの内容ないようと合あっているものはどれか。
    1. 土曜日どようびの午前ごぜんは、エレベーターが使つかえない。
    2. 土曜日どようびは、一日中いちにちじゅうエレベーターが使つかえない。
    3. 十一月じゅういちがつ二十一日から、エレベーターの工事こうじが始はじまる。
    4. 管理人室かんりにんしつで点検てんけんの結果けっかを教おしえてくれる。
  2. 重おもい荷物にもつを運はこぶ必要ひつようがある人ひとは、どうすればよいか。
    1. 正午しょうごまで待まつ。
    2. 管理人室かんりにんしつに連絡れんらくする。
    3. 管理組合かんりくみあいに手紙てがみを書かく。
    4. 階段かいだんを使つかわないようにする。
答案

1 是 1：停止時間是星期六上午九點至中午，所以上午不能用。2 說過頭（一整天）；3 日期是點檢的日子，不是工程開始（沒有「工事」）；4 文中沒寫。〜のため 在第 26 章的新聞句型裏出現過，表示原因。

2 是 2：なお、〜お急いそぎの方かたは、管理人室かんりにんしつまでご連絡れんらくください。選項 1 是不急的做法，不是「必要運送」的人。

考試熱身：問題11 内容理解（中文）

讀下面的文章，回答問題。

日本語にほんごには、擬音語ぎおんごや擬態語ぎたいごが非常ひじょうに多おおい。「ふわふわ」「しとしと」のような言葉ことばは、辞書じしょで説明せつめいすると長ながくなるが、日本人にほんじんはその感覚かんかくを一言ひとことで共有きょうゆうできる。

では、なぜ日本語にほんごにはこのような言葉ことばが多おおいのだろうか。一つの説せつは、感覚かんかくを細こまかく表あらわす動詞どうしや形容詞けいようしが少すくなかったため、擬音語ぎおんごや擬態語ぎたいごがその役目やくめを果はたしてきた、というものである。たとえば雨あめなら、「ざあざあ」「しとしと」「ぱらぱら」と使つかい分わけることで、降ふり方かたの違ちがいを一語いちごで伝つたえられる。

ただし、この説明せつめいには異論いろんもある。擬態語ぎたいごは日本語にほんごだけの特徴とくちょうではなく、ほかの言語げんごにも多おおく見みられるからだ。そのため、日本語にほんごに特とくに多おおいのかどうかは、研究者けんきゅうしゃの間あいだでも意見いけんが分わかれている。

確たしかなのは、こうした言葉ことばが、今いまも日常にちじょうの中なかで新あたらしく生うまれ続つづけているということだ。
  1. 下線部かせんぶ「この説明せつめい」は、どんな説明せつめいか。
    1. 擬態語ぎたいごは、辞書じしょでは説明せつめいできない。
    2. 感覚かんかくを表あらわす動詞どうしなどが少すくなかったので、擬音語ぎおんごや擬態語ぎたいごが多おおくなった。
    3. 雨あめの降ふり方かたは、擬音語ぎおんごでしか表あらわせない。
    4. 日本人にほんじんは、他ほかの国くにの人ひとより感覚かんかくが細こまかい。
  2. 研究者けんきゅうしゃの間あいだで意見いけんが分わかれているのは、何なにについてか。
    1. 擬態語ぎたいごが辞書じしょに必要ひつようかどうか
    2. 日本語にほんごに擬音語ぎおんごや擬態語ぎたいごが特とくに多おおいかどうか
    3. 新あたらしい擬態語ぎたいごが生うまれているかどうか
    4. 雨あめの言葉ことばがいくつあるか
  3. 筆者ひっしゃが「確たしかだ」と考かんがえていることは何なんか。
    1. 日本語にほんごは他ほかの言語げんごより擬態語ぎたいごが多おおい。
    2. 擬態語ぎたいごは外国語がいこくごから入はいってきた。
    3. 擬音語ぎおんごや擬態語ぎたいごは、今いまも新あたらしく生うまれている。
    4. 辞書じしょを見みても、意味いみは分わからない。
答案和分析

文章結構：①現象；② では 提問，帶出「一個說法」；③ ただし 轉折，指出說法有異議；④ 作者唯一確定的事。
