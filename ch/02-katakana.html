第 2 章

片假名與外來語

那些方方正正的字，其實大部分是英文，只是換了一身日本衣服。

嘉欣，下北沢的咖啡店，第一天上班平假名練了一個星期，我已經不是文盲了！今天一定沒問題。

山本店長はい、メニュー。

嘉欣，看著餐牌カフェラテ、カプチーノ、チーズケーキ……這些方方的字是甚麼？一個平假名也沒有！

客人すみません、アイスカフェラテ、お願ねがいします。

嘉欣，心想「アイス」……「カフェ」……「ラテ」？ 等等，ice café latte？ 原來是凍鮮奶咖啡！

山本店長ありがとうございます！

嘉欣第一天就碰上了日語的第二套文字：片假名。它的讀音和平假名一模一樣，只是字形不同，而且多數用來寫外來語。日本的咖啡店、便利店、藥妝店、電器舖，招牌和價錢牌上一大片都是片假名。

壞消息：你又要認 46 個新字形。好消息有兩個。第一，讀音你已經全部懂了，カ 就是 か，不用再學一次發音。第二，片假名寫的詞，大部分來自英文，而你的英文不錯。只要掌握英文變成片假名的幾條規律，很多詞一看就猜得到。

平假名學聲音，片假名學「偽裝」。

規則 1：同一套聲音，另一套字形

片假名和平假名是同一個五十音的兩套字型，就像英文的大楷和細楷：か 和 カ 都讀 ka，分別只在於用在甚麼地方。看看這句客人點餐時說的話，註解標出每一部分的來源：

アイスice カフェcafé ラテlatte ／ チーズcheese ケーキcake

按一下聽聽：アイスカフェラテ、チーズケーキ。你應該已經聽得出 ice、café、latte、cheese、cake。

片假名主要負責這幾種詞：

  • 外來語：從外語借來的詞，大部分來自英文：コーヒー（coffee）、テレビ（television）、バス（bus）。
  • 外國人名和地名：マイケル（Michael）、アメリカ（America）、ロンドン（London）。
  • 擬聲詞和擬態詞，特別是漫畫裏的效果字：ワンワン（狗吠聲）、ドキドキ（心跳加速）。
  • 想突出的字：招牌和廣告有時故意把普通的詞寫成片假名，效果就像英文全用大楷，特別醒目。

中國、韓國、台灣這些用漢字的地方，日語照用漢字寫，例如 中国ちゅうごく、台湾たいわん。香港ホンコン 雖然也寫漢字，讀音卻是片假名的 ホンコン，跟英文 Hong Kong 一樣，來自廣東話。

怎樣背最快？不要對著表死記，要拿真實的詞來練。建議你今天就做一件事：用片假名寫出你最常吃的十樣東西。ラーメン、カレー、ピザ、ハンバーガー……寫的時候讀出聲，寫錯了就翻表。然後下次去便利店，逐個讀出貨架上的片假名。一個星期後，你會發現自己讀餐牌的速度快了很多，因為每一個詞都同時在訓練眼睛、手和耳朵。

中文腦：片假名是楷書的「零件」

第 1 章說過，平假名是整個漢字寫成草書。片假名剛好相反：它取的是漢字楷書的一部分，所以叫「片」假名，「片」就是一部分、碎片的意思。早期的僧侶在佛經旁邊註讀音，地方窄，於是只寫漢字的一角。

規則 3：長音用一條橫線「ー」

平假名的長音要加 あ、い、う 之類的字，還要記「え段加い、お段加う」這些規則。片假名簡單得多：一律加一條橫線 ー，叫「長音符號」。前面是甚麼元音，就把它拉長一拍。

  • コーヒー（kōhī，咖啡）：コ・ー・ヒ・ー，四拍
  • ケーキ（kēki，蛋糕）
  • スーパー（sūpā，超級市場）
  • メニュー（menyū，餐牌）

長音一樣會改變意思，而且這一對你在日本一定用得著：

ビル兩拍：大廈 ／ ビール三拍：啤酒

ビル 是 building 的簡稱，指大廈；ビール 是啤酒。在居酒屋說成 ビル，店員大概會笑著猜到你的意思；在地產公司說成 ビール，就只會換來一臉問號。同樣，ステッキ（拐杖）和 ステーキ（牛扒）也只差一點點。

日語直寫的時候，長音符號也跟著轉成直的一豎。招牌直排時見到一條豎線，不是「丨」字，是長音。

小心！長音符號不是漢字「一」

打字時，長音符號 ー 在日文輸入法按減號鍵 - 就有。不要用中文輸入法打一個「一」字代替，也不要用破折號。三者在螢幕上很像，電腦卻當成完全不同的字，搜尋 コ一ヒ一（用了漢字「一」）甚麼也找不到。

同樣要小心的「漢字分身」：片假名 ロ（ro）和漢字「口」、エ（e）和「工」、カ（ka）和「力」、ニ（ni）和「二」、ハ（ha）和「八」。看前後文判斷：夾在片假名中間的，多數是片假名。

規則 4：促音 ッ 和拗音，也是細寫

細寫的 ッ 跟平假名的 っ 一樣，停一拍。外來語裏它特別多，因為英文很多短元音後面緊接 p、t、k 之類的「塞音」，日語就用 ッ 去模仿那種急停的感覺：

  • cup → カップ（kappu）
  • bed → ベッド（beddo）
  • hot → ホット（hotto），咖啡店的「熱飲」
  • bag → バッグ（baggu），手袋

拗音同樣常見：シャツ（shirt，恤衫）、ジュース（juice，果汁）、チョコレート（chocolate）。ショッピング（shopping）一個詞就集齊拗音、促音和撥音。

英文的「短而急」＝ ッ。

長音寫成 ō、ī，或者寫成 oo、ii、ou 都可以。ッチ 在平文式寫 cchi，不是 tchi，不過兩種你都會見到。ティ 是新的組合，下面規則 6 會講。

規則 5：シ和ツ、ソ和ン，看筆畫的方向

片假名筆畫少，線條直，於是出現了幾對「雙胞胎」。最惡名昭彰的是這四個：

シshi ツtsu ／ ソso ンn

分辨的秘訣在於筆畫的方向，而不是點的位置：

  • シ：兩點排在左邊，橫著放，像兩滴水滑向右邊；長的一筆由左下向右上挑上去。
  • ツ：點排在上面，豎著寫；長的一筆由右上向左下撇下來。
  • ソ：短的一點在上面，接近直豎；長的一筆由上向下撇。
  • ン：短的一點在左邊，接近打橫；長的一筆由下向上挑。

口訣：「上面落雨是ツ、ソ，左邊吹風是シ、ン。」ツ 和 ソ 的點從天上掉下來；シ 和 ン 的點從左邊吹過去，最後一筆向上挑。

按一下聽聽它們在詞語裏的樣子：シャツ（恤衫）一個詞就同時有 シ 和 ツ；ソース（醬汁）和 パン（麵包）各有一個 ソ 和 ン。

小心！其他長得很像的片假名

  • ク（ku）、ケ（ke）、タ（ta）：タ 裏面多一點；ケ 的橫線伸出右邊。
  • ウ（u）、ワ（wa）、フ（fu）、ラ（ra）：ウ 頭上有一點；ラ 上面多一短橫；ワ 左邊有一豎；フ 只有一筆。
  • ス（su）和 ヌ（nu）：ヌ 中間那一筆穿過去，像「又」。
  • チ（chi）和 テ（te）：チ 頂上是一撇，テ 頂上是一橫。
  • マ（ma）和 ム（mu）、ノ（no）和 メ（me）、ユ（yu）和 コ（ko）。

手寫時把 シ、ツ、ソ、ン 寫得規規矩矩，比甚麼都重要。日本人自己寫得潦草也看得懂，因為他們靠上文下理；你還沒有那種詞彙量，只能靠字形。

第 3 題的 バン 讀 ban，是 van（客貨車）。第 6 題的 ファ 用了細寫的 ァ，寫成大的 ア 就變成 fua 兩拍了。這種細寫的組合，下一節就講。パン 為甚麼不是英文 bread？答案在規則 8。

規則 6：新組合，專為外來語而設

傳統五十音沒有 ti、fa、we 這些音。日本人為了寫外來語，發明了一批新組合：在假名後面加一個細寫的元音（ァ、ィ、ゥ、ェ、ォ），把兩格合成一拍。原理跟拗音一樣，只是細寫的字換了。

嘉欣住的 シェアハウス，子軒寫程式用的 ウィンドウ，全部要靠這些組合。

ヴ 是在 ウ 上加兩點，模仿英文的 v。不過日語本身沒有 v 音，大部分人照樣讀成 b，所以很多詞有兩種寫法，而較普遍的往往是 b 的那一個：バイオリン 比 ヴァイオリン 常見，ビデオ（video）幾乎沒有人寫成 ヴィデオ。

還有一點：這些組合比較新。很早以前借進日語的詞，用的是舊方法，把 ti 寫成 チ、di 寫成 ジ 或 デ：チケット（ticket）、ラジオ（radio）、デジタル（digital）。所以同一個英文音，在不同年代的詞裏寫法不同。這不是你記錯，是日語的「版本歷史」。

舊詞用舊 API，新詞用新 API，兩套並存。

規則 7：英文變片假名的五條規律

日語幾乎每一拍都以元音收尾，而且子音和元音都比英文少。英文詞要「擠」進日語的聲音系統，就得按規律變形。掌握以下五條，你聽到陌生的片假名，也能反推出英文原詞。

英文幫到你：五條變形規律

1. 子音後面補一個元音。英文的 bus 尾音是 s，日語沒有單獨的 s，就補成 ス（su）。補甚麼元音有規律：

  • t、d 後面補 o：test → テスト、card → カード
  • ch、j 的音後面補 i：lunch → ランチ、orange → オレンジ
  • 其餘子音補 u：bus → バス、milk → ミルク、golf → ゴルフ

所以一個音節的 milk 在日語變成三拍：ミ・ル・ク。也有一些舊詞補 i，例如 cake → ケーキ、steak → ステーキ，當成例外記住。

2. l 和 r 都變成ら行。日語只有一個介乎兩者之間的音，所以 rice 和 lice 都是 ライス，right 和 light 都是 ライト，glass 和 grass 都是 グラス。放心，日本的餐廳只會賣你飯，不會賣蝨子。

3. 字尾的 -er、-or、-ar 變成長音 ー。日語借詞時多數跟英式讀音，r 不捲舌，只把元音拉長：computer → コンピューター、elevator → エレベーター、car → カー。字中間的 r 也一樣：party → パーティー、park → パーク。

4. 英文的長元音和雙元音，大多變成長音。cake 的 a（ei）→ ケーキ；coat 的 o（ou）→ コート；cheese 的 ee → チーズ。不過 ice 的 ai、out 的 au 照讀兩拍：アイス、アウト。

5. 日語沒有的音，找最近的代替。th → s 或 z：three → スリー、mother → マザー。v → b：video → ビデオ。si → shi：sea 和 she 都是 シー。短元音後面的 p、t、k 加 ッ（規則 4）：cup → カップ。

規律 2 和 5 一起，會令幾個英文詞在日語裏「撞名」。最有名的是 ベスト：可以是 best（最好），也可以是 vest（背心）。日本人靠上文下理分辨，你也一樣。

反過來，這些規律也解釋了為甚麼很多日本人說英文會帶著元音尾巴：他們不是故意的，日語的「每拍有元音」已經寫進他們的口腔肌肉裏。你學日語要做的，正好是相反的訓練：把你的英文發音「日本化」。讀 マクドナルド（McDonald's）時，要老老實實讀出六拍 マ・ク・ド・ナ・ル・ド，日本人才聽得懂。

削尖你的鉛筆

用上面五條規律，把英文詞寫成片假名。打開日文輸入法，打完不要轉漢字。長音用減號鍵打 ー。

  1. bus →
  2. test →
  3. hotel →
  4. taxi →
  5. menu →
  6. computer →
答案

バス、テスト、ホテル、タクシー、メニュー、コンピューター。

taxi 的 x 是 k + s 兩個子音，各補一個 u：ク・シ，最後的 i 拉長成 シー。computer 寫成 コンピュータ（沒有最後的長音）也對，這是工程界和舊式說明書的習慣寫法，不過一般文章現在多數加上 ー。

同一時間，大阪的辦公室

規律有沒有用，拿真實環境測試一下。子軒剛調到大阪分公司，第一天開電腦，佐藤さん遞給他一張紙條。

佐藤さんはい、パスワード。

子軒，看著紙條紙條上有兩行字。パスワード……pa-su-wā-do……password！メールアドレス，mail address，就是電郵地址。

子軒，打開電腦畫面寫著 ログイン、サーバー、データ、ミーティング……原來日本的工程師每天都在讀英文，只是讀得很慢。

佐藤さんほな、よろしく。

子軒，心想最後那句我聽不懂。算了，先說 ありがとうございます 總不會錯。

子軒碰到的詞，正好把規則 7 全部用了一遍。パスワード：word 的 or 變成長音 ワー，尾音 d 補 o 變 ド。サーバー：server 的 er 出現兩次，兩次都變長音，v 變 b。データ：data 跟英式讀音 day-ta，雙元音 ei 變長音 デー。ミーティング：ee 變長音，ti 用新組合 ティ，ng 變 ング。

用規律推一推，以下這些 IT 詞你應該全部猜得出：プログラム、ソフト、バグ、スケジュール、プリンター。（program、software、bug、schedule、printer。ソフト 又是一個剪掉後半的詞。）

至於佐藤さん最後那句 ほな，那是關西腔的「那麼」，標準語是 では。子軒在大阪會常常聽到，以後的關西腔方塊再慢慢介紹。

規則 8：和製英語，看得懂的英文，猜不中的意思

好了，你現在以為片假名就是「用日本口音讀英文」。可惜事情沒有那麼簡單。片假名裏有三類詞，用英文去猜會中伏。

第一類：不是來自英文

日本最早接觸的西方人是葡萄牙人和荷蘭人，所以一些很老的外來語來自這兩種語言。パン（麵包）來自葡萄牙語 pão，コーヒー 來自荷蘭語 koffie，所以不是「カフィー」。アルバイト（兼職）更來自德語 Arbeit（工作），日常簡稱 バイト。嘉欣在咖啡店的工作，就是一份 バイト。

第二類：英文詞，日本意思

這是最危險的一類。詞本身是英文，意思卻變了：

  • マンション：不是豪宅 mansion，而是鋼筋水泥的住宅大廈單位，跟香港的「屋苑單位」差不多。
  • コンセント：不是「同意」consent，而是牆上的電源插座。
  • スマート：多數指身材苗條，不一定是聰明。
  • サービス：除了「服務」，還常常指「免費送的」。店員說這杯咖啡是 サービス，意思是不收錢。

第三類：日本人自己砌出來的「英文」

用英文零件砌出英文裏沒有的詞，再剪短。這是和製英語最有趣的地方：

  • personal computer → パーソナルコンピューター → パソコン（電腦）
  • air conditioner → エアコン（冷氣機）
  • remote control → リモコン（遙控）
  • convenience store → コンビニ（便利店）
  • smartphone → スマホ（智能電話）

你看出規律了嗎？兩個詞各取頭兩拍，合起來剛好四拍：パソ + コン、リモ + コン。日語特別喜歡四拍的詞，讀起來有節奏感。

像把 personal_computer 改名成 pc，只是日本人習慣留四拍。

還有一些是直接用英文零件「發明」的：サラリーマン（salary + man，上班族）、ガソリンスタンド（gasoline + stand，油站）、ペットボトル（PET + bottle，膠樽）、ノートパソコン（notebook + パソコン，手提電腦）。拿去跟英語國家的人說，他們多數聽不懂。

就算不砌新詞，日語也很喜歡把長的外來語剪掉後半：television → テレビ、department store → デパート、supermarket → スーパー、apartment → アパート（多指兩三層高的出租公寓，比 マンション 小）。聽到一個片假名詞覺得「好像只說了一半」，多數真的只說了一半。

動動腦

ワンピース 是 one + piece。ベビーカー 是 baby + car。フライドポテト 是 fried + potato。只看零件，你猜它們分別是甚麼東西？（提示：一件衣服、一件嬰兒用品、一款快餐食物。）

中文腦：廣東話早就在「片假名化」

香港人對這套玩法其實很熟。廣東話借英文詞的方法，跟日語幾乎一樣：用本土的音節去模仿英文，子音後面也會補元音。

英文廣東話日語
bus巴士 baa1 si2バス
taxi的士 dik1 si2タクシー
cheese芝士 zi1 si2チーズ
sandwich三文治 saam1 man4 zi6サンドイッチ
chocolate朱古力 zyu1 gu1 lik1チョコレート

留意 bus：廣東話在 s 後面補 i（巴「士」），日語補 u（バ「ス」）。思路一樣，只是補的元音不同。你遇到陌生的片假名，試試用讀廣東話外來語的方法去讀，常常一下子就猜中。

普通話比較喜歡意譯：電腦、冷氣、手機，看字就知道意思。不過音譯詞也不少，例如沙發 shāfā（ソファ）、咖啡 kāfēi（コーヒー）、巧克力 qiǎokèlì（チョコレート）。講普通話的讀者，就從這些詞入手。

小心！和製英語的假朋友

以下幾個詞在日本天天聽到，意思跟英文差得最遠：

  • クレーム（claim）：投訴。「客人打來 クレーム」是有人投訴，不是索償。
  • カンニング（cunning）：考試作弊。
  • テンション（tension）：興奮程度、情緒高低。「テンション 很高」是很興奮，不是很緊張。
  • マイペース（my pace）：按自己節奏做事，帶一點「我行我素」的味道。

反過來，你在日本說英文時也要小心：跟日本同事說 consent，他可能以為你要找插座。

配對遊戲

這些和製英語在日本到處都見到。每一個是甚麼意思？

  1. パソコン →
  2. コンセント →
  3. マンション →
  4. エアコン →
  5. リモコン →
  6. アルバイト →
  7. サラリーマン →
  8. ペットボトル →
答案

パソコン 電腦、コンセント 電源插座、マンション 住宅大廈單位、エアコン 冷氣機、リモコン 遙控、アルバイト 兼職、サラリーマン 上班族、ペットボトル 膠樽。

動動腦的答案也順便公布：ワンピース 是連身裙，ベビーカー 是嬰兒車，フライドポテト 是薯條。

先學三句「整句背」的日語

文法要到下一章才開始，但在咖啡店上班，嘉欣今天就要開口。以下三句是固定說法，先當成一整塊背下來，不用拆開分析：

  • いらっしゃいませ：歡迎光臨。客人一進門，全店員工一起喊。
  • ありがとうございます：謝謝（禮貌）。比 ありがとう 客氣，對客人、上司、陌生人都用這個。
  • すみません：對不起、不好意思，也用來叫人：「すみません！」就是在餐廳舉手叫店員的那一句。

注意 ありがとうございます 的 とう 讀長音 tō，而 ございます 最後的 su 輕得幾乎聽不見，聽起來像 gozaimas；すみません 開頭的 su 也讀得很輕，像 s'mimasen。按一下聽聽，跟著讀三次。

考試熱身：表記

JLPT N5「文字・語彙」的問題 2（表記）會給你一個用平假名寫的詞，要你選出正確的寫法，片假名詞也會考。四個選項常常只差一點、一條長音線，或者一對雙胞胎字。按 ▶ 聽讀音，再選出正確的片假名。

  1. てれび
  2. びーる
  3. しゃつ
  4. のーと
  5. すぷーん
答案

1 テレビ（電視）、2 ビール（啤酒）、3 シャツ（恤衫）、4 ノート（筆記簿）、5 スプーン（匙羹）。

第 2 題的 ビーノレ 是個陷阱：ノ 和 レ 靠得太近，看起來就像 ル。第 3 題的 シヤツ 用了大的 ヤ，讀成 shi-ya-tsu 三拍。第 4 題的 ノート 是 notebook 剪短的，指筆記簿，不是「註釋」。

沒有蠢問題

平假名和片假名，要先熟哪一套？
平假名。句子的骨架全靠平假名，片假名主要出現在名詞裏。不過片假名也不能拖：日本的餐牌、價錢牌、電器說明書全是片假名，而且 JLPT 一樣會考。建議平假名熟了之後，花一兩個星期專攻片假名。
英文詞可以自己「片假名化」嗎？
可以猜，但不一定猜中。同一個英文詞，日語可能根本不用（用漢字詞代替），可能剪短了，也可能意思不同。見到新的片假名詞，用規則 7 推敲英文原詞，再查字典確認意思。
為甚麼有些詞有兩種寫法，例如 コンピューター 和 コンピュータ？
外來語的寫法沒有百分百統一。日本政府有一份外來語表記的指引，建議 -er 一類的字尾加長音，但工程和科技界一直有省略長音的習慣。兩種你都會見到，自己寫的時候跟一般寫法，加 ー。
我的名字要用片假名寫嗎？
英文名用片假名：Michael 是 マイケル。中文名可以寫漢字，讀成日語的音讀，也可以用片假名模仿原來的讀音。嘉欣在日本自我介紹時用廣東話讀音的片假名 カーヤン，下一章你會聽到她用。
日語的外來語是不是越來越多？
是的，特別是 IT、時裝和商業的詞，新的片假名詞年年出現。連日本的長輩也常常抱怨看不懂，一些政府機構甚至會在文件裏把太新的片假名詞改寫成漢字詞或加上解釋。對你來說這其實是好事：英文底子越好，日語詞彙就越容易擴充。
片假名詞一長，我就讀得很慢，怎麼辦？
很正常，日本小朋友也一樣。試試兩個方法。第一，先找長音 ー 和 ッ，把詞切成幾段，例如 エレ・ベー・ター。第二，一邊讀一邊想英文，讀到 エレベー 時腦裏已經跳出 elevator，後半就不用逐個字拼了。讀得越多，眼睛越會整塊整塊地認。
看到漫畫裏的 ドキドキ、ワクワク，要背嗎？
現階段不用。這些擬聲擬態詞多數用重複的四拍寫成，日常會話很常見，以後的章節會慢慢加入。先把外來語讀順就夠了。

重點整理

  • 片假名和平假名讀音完全相同，字形不同。片假名取漢字楷書的一部分，「片」就是一部分。
  • 片假名主要寫外來語、外國人名地名、擬聲詞，以及想突出的字。
  • 長音一律用 ー：ビル（大廈）≠ ビール（啤酒）。
  • 促音 ッ 模仿英文短元音後的急停：カップ、ベッド。
  • シ／ツ、ソ／ン 看筆畫方向：上面落雨是 ツ、ソ，左邊吹風是 シ、ン。
  • 新組合加細寫元音：ティ、ファ、ウェ、シェ、ヴ。舊詞用舊寫法：チケット、ラジオ。
  • 英文變片假名：子音後補元音，l／r 都變ら行，-er 變 ー，長元音變 ー，沒有的音找最近的。
  • 和製英語要小心：マンション 是住宅單位，コンセント 是插座，パソコン 是剪成四拍的 personal computer。
  • 先整句背：いらっしゃいませ、ありがとうございます、すみません。
