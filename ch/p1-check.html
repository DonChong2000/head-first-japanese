N5 自測：第一部分的期末考

十章讀完了。是時候跑一次單元測試，看看哪個函式還有 bug。

這份自測照足 JLPT N5 的題型和次序：先是言語知識（文字・語彙），然後是文法和讀解，最後是聽解。每種題型一個方塊，題目只用第 1 至 10 章教過的文法和 N5 詞語，共 55 題。

怎樣做這份自測

  • 不要偷看。做完一個方塊才按「檢查」，再打開答案。答案會逐個選項解釋，錯了的要看，對了的也值得看一眼，因為你可能只是猜中。
  • 計時。真試每一節的時間以 jlpt.jp 公布為準，這裏不抄數字。建議一口氣由頭做到尾，記下用了多久，下次重做時比較。
  • 聽解只聽一次。真試每段錄音只播一次。按 ▶ 聽完就作答，不要重播。答完才打開答案看文字稿，再自己把文字稿讀出來。
  • 聽解由瀏覽器朗讀，男女同一把聲音，所以錄音裏會讀出「男」「女」標明誰在說話。真試要你看圖的地方，這裏改用文字選項或中文情境說明。
  • 文字・語彙問題 1 和問題 2 考的就是漢字讀法和寫法，所以題目句按了不會發聲，被考的詞也沒有振假名。

先做完，再對答案。邊做邊看答案，等於考試時翻書。

真試的計分方法：N5 滿分 180，合格要 80 分，而且「言語知識（文字・語彙・文法）・讀解」不可少於 38 分，「聽解」不可少於 19 分。考試時間和最新細則請看 jlpt.jp。

言語知識（文字・語彙）

考試熱身：問題1 漢字読み（漢字讀法）

劃了線的詞怎樣讀？選出正確的平假名。

  1. わたしは白いかばんを持もっています。
  2. 先月、京都きょうとへ行いきました。
  3. このパンは六百円です。
  4. 毎朝まいあさ電車で会社かいしゃへ行いきます。
  5. 四月しがつ二十日は何曜日なんようびですか。
答案

1 しろい：「白」的訓讀是 しろ。くろい 是「黑」，跟「白」無關；しらい、しるい 根本不是詞。

2 せんげつ：「先月」的「月」讀 げつ。がつ 只用於月份名稱（四月しがつ）；さき 和 つき 是訓讀，不會跟音讀混在這個詞裏。

3 ろっぴゃくえん：六加百，變成促音加半濁音。ろくひゃく 是照字硬讀，ろっひゃく 漏了半濁音，ろくびゃく 是把三百 さんびゃく 的規則搬錯地方。

4 でんしゃ：「電」讀 でん（有濁點），「車」讀 しゃ（沒有濁點）。其餘三個都是濁點放錯位置。

5 はつか：二十日是特別讀法，要死記。ふつか 是二日，ようか 是八日，はつにち 不存在。

考試熱身：問題2 表記（寫法）

劃了線的詞，用漢字或片假名應該怎樣寫？

  1. やすみの日ひに友達ともだちと会あいました。
  2. 毎晩まいばんてれびを見みます。
  3. 駅えきのきたに大おおきい公園こうえんがあります。
  4. 夜よる、母ははにでんわをかけました。
答案

1 休やすみ：人字旁加「木」，人靠著樹休息。体（身體）也是人字旁，最容易選錯；木み、本み 不是詞。

2 テレビ：テレピ 把濁音寫成半濁音，デレビ 把第一拍寫成濁音，テルビ 中間那拍錯了。外來語先讀出來，一拍一拍對。

3 北きた：比、化、兆 樣子相近，但都不讀 きた。東西南北四個字最好一起記。

4 電話でんわ：雷（打雷）和「電」只差下面那一筆；語 是語言的「語」，讀 ご，不讀 わ。

考試熱身：問題3 文脈規定（按上文下理選詞）

（　）裏面放哪一個最合適？

  1. 暗くらいですね。電気でんきを（　）ください。
  2. えんぴつを三さん（　）買かいました。
  3. 毎朝まいあさ、歯はを（　）。
  4. （　）は日曜日にちようびでした。今日きょうは月曜日げつようびです。
  5. 駅えきで切符きっぷを（　）、電車でんしゃに乗のりました。
答案

1 暗くらいですね。電気でんきをつけてください。 開燈是 つける。けして 是關燈，房間暗了還關燈說不通；あけて、しめて 用在門窗。

2 えんぴつを三本さんぼん買かいました。 筆、樽裝飲品這類細長的東西用「本」，三本讀 さんぼん。まい 數紙、碟這類薄片，ひき 數小動物，にん 數人。

3 毎朝まいあさ、歯はをみがきます。 刷牙是 はをみがく。あびます 配シャワー（淋浴），はきます 配鞋和褲，ききます 是聽。

4 きのうは日曜日にちようびでした。 今天星期一，星期日就是昨天。おととい 是星期六；あした、あさって 是將來，配不上過去式 でした。

5 駅えきで切符きっぷをかって、電車でんしゃに乗のりました。 買車票，然後上車。おりる（下車）、つかれる（疲倦）、はたらく（工作）都不能帶「切符きっぷを」做賓語。

考試熱身：問題4 言い換え類義（意思相近的句子）

哪一句的意思跟劃了線的句子最接近？選出號碼。

  1. この部屋へやはくらいです。
    1. この部屋へやはあかるくないです。
    2. この部屋へやはせまくないです。
    3. この部屋へやはあかるいです。
    4. この部屋へやはひろいです。
  2. おととい、友達ともだちに会あいました。
    1. きのう、友達ともだちに会あいました。
    2. 先週せんしゅう、友達ともだちに会あいました。
    3. 二日ふつか前まえに、友達ともだちに会あいました。
    4. 三日みっか前まえに、友達ともだちに会あいました。
  3. 山田やまださんはりょうしんと住すんでいます。
    1. 山田やまださんは兄あにと姉あねと住すんでいます。
    2. 山田やまださんは祖父そふと祖母そぼと住すんでいます。
    3. 山田やまださんは弟おとうとと妹いもうとと住すんでいます。
    4. 山田やまださんは父ちちと母ははと住すんでいます。
  4. わたしは料理りょうりがへたです。
    1. わたしは料理りょうりがじょうずです。
    2. わたしは料理りょうりがじょうずじゃありません。
    3. わたしは料理りょうりがすきじゃありません。
    4. わたしは料理りょうりがきらいです。
答案

1 是 1：くらい（暗）等於 あかるくない（不光）。這是 N5 最愛的出題方法：反義詞加否定。3 意思相反；2 和 4 講的是大小，不是光暗。

2 是 3：おととい 是前天，即兩日前。1 是昨天，4 是三日前，2 是上星期。

3 是 4：りょうしん（両親）就是父母。其餘三個是兄姊、祖父母、弟妹。

4 是 2：へた（下手）就是不擅長，等於 じょうずじゃありません。3 和 4 講喜不喜歡，跟會不會是兩回事：很多人喜歡唱歌，卻唱得很差。

言語知識（文法）・讀解

考試熱身：問題1 文法形式の判断（選文法形式）

（　）裏面放哪一個最合適？

  1. 図書館としょかん（　）本ほんを読よみます。
  2. 弟おとうとはわたし（　）背せが高たかいです。
  3. すみません、ここで写真しゃしんを（　）もいいですか。
  4. きのうのテストは（　）。
  5. A：土曜日どようび、いっしょに映画えいがを見み（　）。
    B：いいですね。見みましょう。
答案

1 図書館としょかんで本ほんを読よみます。 「讀書」這個動作在圖書館發生，用 で。に 是存在的地點或目的地，へ 是方向，を 已經給了「本」。

2 弟おとうとはわたしより背せが高たかいです。 A は B より～ 是比較句。から、まで 是起點和終點；ほど 要配否定句，這裏是肯定句。

3 ここで写真しゃしんをとってもいいですか。 ～てもいいですか 一定接て形：とる → とって。其餘三個形式都接不上 も。

4 きのうのテストはむずかしかったです。 い形容詞的過去式是把 い 換成 かった，再加 です。むずかしいでした 是中文讀者最常犯的錯，因為 な形容詞（しずかでした）才用 でした。

5 いっしょに映画えいがを見みませんか。 B 回答「見ましょう」，可見 A 是在邀請，用 ませんか。ましたか、ませんでしたか 問過去，配不上「星期六」和 B 的回答；ていますか 問的是正在做或狀態。

考試熱身：問題2 文の組み立て（★ 排句）

把四個部分排成一句通順的句子，★ 的位置放的是哪一個？選出號碼。

  1. つくえの　＿＿　＿＿　★　＿＿　います。
    1 した　2 が　3 ねこ　4 に
  2. ここに　＿＿　＿＿　★　＿＿　ください。
    1 を　2 かいて　3 なまえ　4 あなたの
  3. ＿＿　＿＿　★　＿＿　富士山ふじさんがいちばん高たかいです。
    1 の中なかで　2 山やま　3 日本にほん　4 の
  4. 宿題しゅくだいを　＿＿　＿＿　★　＿＿　見みます。
    1 から　2 を　3 して　4 テレビ
答案

做法：先不理 ★，把四塊排成整句，最後才數到第三格。

1 是 3：つくえの　した　に　ねこ　が　います。 Place に Thing が います，第 10 章的句型。

2 是 1：ここに　あなたの　なまえ　を　かいて　ください。 「あなたの」一定放在名詞前面，「を」一定緊接「なまえ」。

3 是 2：日本にほん　の　山やま　の中なかで　富士山ふじさんがいちばん高たかいです。 ～の中で～がいちばん，第 7 章的最高級句型。

4 是 4：宿題しゅくだいを　して　から　テレビ　を　見みます。 ～てから，做完一件事才做下一件。

考試熱身：問題3 文章の文法（文章填空）

留學生寫了一篇作文。（1）至（4）放哪一個最合適？

わたしの毎日まいにち

わたしは香港ホンコンから来きました。今いま、東京とうきょうのシェアハウスに住すんでいます。

わたしは下北沢しもきたざわのカフェ（1）働はたらいています。カフェは朝あさ七時しちじから夜よる九時くじ（2）です。仕事しごとは大変たいへんです。（3）、とても楽たのしいです。

日曜日にちようびは休やすみです。先週せんしゅうの日曜日にちようびは、田中たなかさんと浅草あさくさへ（4）。浅草あさくさはとてもにぎやかでした。

答案

（1）で：カフェで働はたらいています，工作這個動作在咖啡店發生。に 配 あります、住すんでいます 這類表示所在的動詞，不配 働はたらきます。

（2）まで：七時しちじから九時くじまで，從幾點到幾點。前面已經有 から，再放 から 就重複了；より 是比較，と 是「和」。

（3）でも：前一句「工作辛苦」，後一句「很開心」，意思相反，要用轉折的「可是」。そして、それから 是順接，だから 是「所以」，都接不上。

（4）いきました：「上星期日」是過去，要用過去式。いきましょう 是邀請，いきたいです 是願望，都不是已經發生的事。

全文：わたしは下北沢しもきたざわのカフェで働はたらいています。カフェは朝あさ七時しちじから夜よる九時くじまでです。仕事しごとは大変たいへんです。でも、とても楽たのしいです。

考試熱身：問題4 内容理解（短文）

讀下面三篇短文，回答問題。先看問題，再回文中找答案。

  1. リーさんへ
    今日きょう、わたしは夜よる十時じゅうじまでアルバイトです。れいぞうこにカレーがあります。食たべてください。食たべてから、おさらを洗あらってください。
    田中たなか

    リーさんは、カレーを食たべてから、何なにをしますか。

    1. カレーを作つくります。
    2. おさらを洗あらいます。
    3. アルバイトに行いきます。
    4. 田中たなかさんに電話でんわをかけます。

  2. シェアハウスのみなさんへ
    あしたの朝あさ、九時くじから十一時じゅういちじまで、おふろを使つかってはいけません。トイレと台所だいどころは使つかってもいいです。
    大家おおや

    あしたの朝あさ十時じゅうじに、何なにを使つかってはいけませんか。

    1. トイレ
    2. 台所だいどころ
    3. おふろ
    4. トイレとおふろ

  3. 佐藤さとうさんは大阪おおさかの会社かいしゃで働はたらいています。毎朝まいあさ七時しちじに起おきます。朝あさごはんを食たべてから、地下鉄ちかてつで会社かいしゃへ行いきます。仕事しごとは九時くじからです。でも、水曜日すいようびは十時じゅうじからです。水曜日すいようびの朝あさは、プールで泳およいでから、会社かいしゃへ行いきます。

    佐藤さとうさんは、水曜日すいようびの朝あさ、何なにをしますか。

    1. 九時くじに会社かいしゃへ行いきます。
    2. 会社かいしゃで朝あさごはんを食たべます。
    3. 七時しちじにプールへ行いきます。
    4. プールで泳およいでから、会社かいしゃへ行いきます。
答案

1 是 2：「食たべてから、おさらを洗あらってください」。咖喱已經在雪櫃裏，不用煮（1）；去打工的是田中（3）；便條沒有提電話（4）。

2 是 3：九時至十一時不准用浴室，十點正在這段時間內。廁所和廚房都可以用，所以 1、2 錯；4 包括了廁所，也錯。

3 是 4：星期三十點才上班，早上先去游泳。1 是平日的上班時間；早餐在家吃（2）；七點是起床時間，文中沒說七點去游泳（3）。

考試熱身：問題5 内容理解（中文）

讀下面的作文，回答問題。

わたしは先月せんげつ、日本にほんへ来きました。今いま、日本語学校にほんごがっこうで勉強べんきょうしています。

先週せんしゅうの土曜日どようび、クラスの友達ともだちと山やまへ行いきました。朝あさ八時はちじに駅えきで会あって、電車でんしゃに二時間にじかんぐらい乗のりました。山やまはとても高たかかったです。山やまの上うえまで、歩あるいて三時間さんじかんかかりました。山やまの上うえで、みんなでおべんとうを食たべました。天気てんきはとてもよかったです。

日曜日にちようびは、うちで休やすみました。足あしがとても痛いたかったです。来月らいげつは、海うみへ行いきたいです。

リー

  1. 山やまの上うえまで、何時間なんじかんかかりましたか。
    1. 一時間いちじかん
    2. 二時間にじかん
    3. 三時間さんじかん
    4. 五時間ごじかん
  2. 日曜日にちようび、リーさんは何なにをしましたか。
    1. 海うみへ行いきました。
    2. 友達ともだちと山やまへ行いきました。
    3. 駅えきで友達ともだちに会あいました。
    4. うちで休やすみました。
答案

1 是 3：「山やまの上うえまで、歩あるいて三時間さんじかんかかりました」。兩小時是坐火車的時間，五小時是把兩個數字加起來的陷阱。讀解題很愛在文中放幾個數字，問的是哪一個要看清楚。

2 是 4：星期日腳痛，留在家休息。去山和在車站集合都是星期六的事（2、3）；去海邊是下個月的願望（1），たい 表示想做，不是做了。

考試熱身：問題6 情報検索（找資料）

這是下北沢一間咖啡店的餐牌。看餐牌，回答問題。

※ランチセットは午前ごぜん十一時じゅういちじから午後ごご二時にじまでです。

  1. マリアさんは午後ごご三時さんじにこのカフェへ行いきます。のみものを一ひとつと、たべものを一ひとつ買かいます。お金かねは七百円ななひゃくえんあります。何なにを買かいますか。
    1. コーヒーとケーキ
    2. ジュースとケーキ

2 是 2：十二點在午餐時段內，咖喱加飲品是套餐價 900 日圓。3 是分開買的價錢（800 + 350），1 和 4 只計了其中一樣。

店みせで、女おんなの人ひとと店みせの人ひとが話はなしています。女おんなの人ひとはどのかさを買かいますか。

考試熱身：問題3 発話表現（這時候說甚麼）

先看情境（真試是一幅圖，箭頭指著說話的人），再按 ▶ 聽三個說法，選出最合適的一個。

  1. 情境：你在餐廳，想叫店員過來。
  2. 情境：在朋友家，飯菜上桌了，你準備開始吃。
  3. 情境：你上課遲到，走進課室時對老師說。
  4. 情境：你想借用朋友的筆。
答案和文字稿

1 是 1：店みせの人ひとを呼よびます。何なんと言いいますか。1 すみません。2 ごめんください。3 いらっしゃいませ。 叫店員說 すみません。ごめんください 是到別人家門口時說的「有人在嗎」；いらっしゃいませ 是店員對客人說的。

2 是 2：友達ともだちの家いえで、ごはんを食たべます。何なんと言いいますか。1 ごちそうさまでした。2 いただきます。3 おじゃまします。 開始吃說 いただきます，吃完才說 ごちそうさまでした；おじゃまします 是進門時說的。

3 是 3：学校がっこうにおくれました。先生せんせいに何なんと言いいますか。1 いってきます。2 おやすみなさい。3 おくれて、すみません。 いってきます 是出門時對家人說的，おやすみなさい 是晚安。

4 是 2：友達ともだちのペンを使つかいたいです。何なんと言いいますか。1 ペンを使つかいましょう。2 ペンを使つかってもいいですか。3 ペンを使つかってください。 借東西要問許可：～てもいいですか。使つかってください 是請對方用，方向相反；使つかいましょう 是「一起用吧」。

考試熱身：問題4 即時応答（即時回應）

沒有圖，也沒有印出來的選項。按 ▶ 聽一句話和三個回應，選出最合適的回應。

答案和文字稿

1 是 1：おくには、どちらですか。1 ホンコンです。2 日本語にほんごです。3 あちらです。 おくに 問你從哪個國家或地方來。どちら 在這裏是「哪裏」的客氣說法，答「あちら」（那邊）是把字面意思當真了。

2 是 3：いつ日本にほんへ来きましたか。1 来年らいねんです。2 ひこうきで来きました。3 去年きょねん来きました。 問「甚麼時候」，答時間；明年是將來，配不上過去式；坐飛機答的是「怎樣來」。

3 是 1：コーヒーと紅茶こうちゃと、どちらがいいですか。1 コーヒーがいいです。2 はい、いいです。3 どういたしまして。 二選一的問題不能答 はい；どういたしまして 是回應道謝的「不客氣」。

4 是 2：この本ほん、借かりてもいいですか。1 はい、借かりました。2 はい、どうぞ。3 どういたしまして。 對方問可不可以借，答 どうぞ（請）。1 說的是自己借了，主語錯了。

5 是 3：きのうのパーティーは、どうでしたか。1 あしたです。2 パーティーに行いきます。3 とても楽たのしかったです。 どうでしたか 問感想，而且是昨天的事，用過去式回答。
