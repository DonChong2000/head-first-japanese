第 26 章

である體與新聞日語

新聞標題沒有動詞，文章沒有です、ます，連句號前面的字都被偷走了。

嘉欣，下北沢的咖啡店，開店前十分鐘店長，櫃檯上這份報紙是給客人看的嗎？

山本店長ええ。毎朝まいあさ、読んでから置おいておくの。嘉欣カーヤンさんも、読んでみて。日本語の勉強べんきょうになるわよ。

嘉欣，盯著頭版一會兒「新駅、来春らいしゅんにも開業かいぎょうへ」……這是甚麼？沒有主語，沒有動詞，最後還有個「へ」。

山本店長それが見出し。新聞の見出しは、普通ふつうの文ぶんじゃないの。短みじかく書くために、言葉ことばを減へらしてあるのよ。

嘉欣じゃあ、中の文章ぶんしょうは？

山本店長文章ぶんしょうは文章ぶんしょうで、また別べつ。「です・ます」を使つかわないでしょう？

嘉欣，低頭看了一行，心想是沒有です、ます。每句都是「〜した。」「〜という。」，像在宣布甚麼。原來報紙是另一種日語。

你到現在學的日語，大致分兩層：朋友之間的普通形（第 11 章），對人有禮貌的です・ます。看新聞、讀論文、寫報告，會遇到第三層：常體（だ・である体たい）。它沒有對話對象，不跟任何人說話，只負責陳述。

這一章講兩件事：怎樣讀「だ・である」的文章，以及新聞特有的兩個習慣：標題的省略法，和正文的句尾。這兩樣是 N2 閱讀題的常客，也是你每天看日本網站會碰到的東西。

規則 1：三套文體，用在三個地方

文體名稱用在哪裏樣子
敬體です・ます体たい對人說話、電郵、信件、說明書明日あしたは雨です。
口語普通形（沒有固定名稱）朋友間說話、日記、社交媒體明日あしたは雨だよ。
常體だ・である体たい新聞、論文、報告書、教科書、評論明日あしたは雨である。

常體和朋友之間的普通形用的是同一組動詞形狀（行く、行った、行かない），所以讀常體的文章，動詞和形容詞你不用重學。分別在三處：句尾的 だ 和 である、整體的用詞、還有不能用口語縮寫。

程式員比喻：口語普通形像 console.log 的輸出，常體像正式的 API 文件。

規則 2：だ 還是 である？

常體的名詞句和な形容詞句，句尾有兩個選擇：

  • だ：比較輕，是新聞、隨筆、評論常用的。これは問題もんだいだ。
  • である：比較重，是論文、報告、學術文章的標準。これは問題もんだいである。

兩者意思沒有差別，只是正式程度。有一點值得知道：新聞並不是「である」的天下。日本報章的正文多數用 だ 結尾，而且大部分句子根本不需要 だ，因為句子以動詞結尾：市しは来月から料金りょうきんを引ひき上げる。只有名詞或な形容詞結尾時，才要在 だ 和 である 之間選。各報社有自己的用字手冊，細節不盡相同，不必當成考試規則。

其他詞性的對照：

敬體常體（書面）
名詞学生です学生だ／学生である
名詞否定学生ではありません学生ではない（不用 じゃない）
名詞過去学生でした学生だった／学生であった
な形容詞静しずかです静しずかだ／静しずかである
い形容詞高いです高い（沒有 だ）
動詞行きます行く
推測降ふるでしょう降ふるだろう／降ふるであろう
條件学生なら学生であれば／学生ならば

留意兩點。第一，い形容詞不能加 だ：高いだ 在書面也是錯的（口語偶爾有人說，書面不行）。第二，〜ている 在書面不能縮成 〜てる，要寫完整。

另外，常體沒有「問句」。不說 行きますか，也不說朋友之間的 行く？。書面要問，用反問或自問自答：なぜ減へったのか。、本当ほんとうに必要ひつようだろうか。、問題もんだいではないか。句尾用 のか、だろうか、ではないか，不加問號也很常見。

你一定有過這個經驗：口頭說「佢唔係學生」，寫文章卻要寫「他不是學生」。粵語和書面中文是兩套系統，你從小就要在腦裏轉換。日語的口語普通形和常體，也是同一回事：

規則 3：書面不用的東西，和書面愛用的東西

口語縮寫一律還原

  • 〜てる → 〜ている：読んでる → 読んでいる
  • 〜ちゃう → 〜てしまう：忘わすれちゃう → 忘わすれてしまう
  • 〜じゃ → 〜では：無理むりじゃない → 無理むりではない
  • 〜なきゃ → 〜なければ：行かなきゃ → 行かなければ
  • 去掉句尾的 よ、ね、さ、な。書面沒有跟人互動，不需要這些語氣詞。
  • ら抜ぬき言葉ことば也不能用：食べれる → 食べられる（第 12 章）。

削尖你的鉛筆：改成常體

把下面的です・ます體或口語句子，改成適合寫在報告裏的常體。選出最合適的一個。

  1. 先月の売うり上げは増ふえましたが、利益りえきは減へりました。
  2. この問題もんだいは簡単かんたんじゃありません。
  3. 天気が悪わるかったから、試合しあいは中止ちゅうしになった。
  4. 子どもの数かずは、だんだん減へってる。
答案

1 是第二個：が 代替口語的 けど，動詞用普通形（増ふえた、減へった）。第三個把敬體和普通形混在一個句子，書面最忌。

2 是第二個：ではない。じゃない 是口語，ではありません 是敬體。

3 是第一個：ため 代替 から。第三個「悪わるいだった」是錯的，い形容詞後面不能加 だ。

4 是第二個：次第しだいに 代替 だんだん，ている 代替 てる。

規則 4：新聞的句尾——記者不說「我覺得」

新聞的規矩是：事實歸事實，推測歸推測，誰說的要標明。所以句尾有一批專用形狀，每一個都在告訴你這句話的「可信度」和「來源」。

句尾意思例
〜した。／〜だ。記者確認的事實市しは十日、発表はっぴょうした。
〜と発表はっぴょうした／明あきらかにした官方公布会社かいしゃは値上ねあげを明あきらかにした。
〜と述のべた／話している某人說市長しちょうは「検討けんとうする」と述のべた。
〜という。據說（來源是報道以外的人）事故じこによるけが人はいないという。
〜とみられる。記者或警方的推定火元ひもとは台所だいどころとみられる。
〜方針ほうしんだ／予定よていだ／見通みとおしだ打算、預定、預計来月から実施じっしする方針ほうしんだ。
〜模様もようだ看樣子（較少見，有點保守）原因げんいんは調査中ちょうさちゅうの模様もようだ。
〜に踏ふみ切きった／〜を見送みおくった下決心做了／決定不做会社かいしゃは新店しんてんの出店しゅってんを見送みおくった。

其中最微妙的是 〜という 和 〜とみられる。句尾的 という 是傳聞：記者沒親眼確認，是聽某人說的，所以後面常是被轉述的情況。〜とみられる 則是記者或調查機關自己的判斷，比 という 更接近「大概」。兩者都比單純的 〜した 弱。新聞的態度是：沒有確認的事，就不能用肯定句。

記者怎樣交代消息來源，也有固定寫法。引用別人說的話用 〜によると（根據……）：市しによると、昨年度さくねんどの利用者りようしゃは約やく三十万人だった。後面接的多是報道、資料、官方說法。

還有一組在新聞中出現率極高，也屬 N2 的連接詞：

  • 〜を受うけて：回應前一件事。知事ちじの発言はつげんを受うけて、市しは対応たいおうを協議きょうぎした。
  • 〜に伴ともない：隨著。工事こうじに伴ともない、駅前の道路どうろが通行止つうこうどめになる。
  • 〜を踏ふまえ：考慮到。調査ちょうさの結果けっかを踏ふまえ、本格実施ほんかくじっしを決きめる。
  • 同どう＋名詞：前面剛提過的那一個。同市どうし（該市）、同社どうしゃ（該公司）、同日どうじつ（同一天）、同氏どうし（該人）。

中文腦：新聞漢字詞，意思會分家

新聞用的漢語詞，中文讀者看字面猜意思，大多對，但幾個最常見的會誤導你：

  • 検討けんとう：考慮、研究，用來表示「正在想要不要做」：導入どうにゅうを検討けんとうしている。中文的「檢討」（粵 gim2 tou2／普 jiǎntǎo）常指反省自己的錯誤，日語完全沒有這個意思。新聞裏的 検討けんとうしている，其實是還沒有決定。
  • 経緯けいい：事情的經過。中文的「經緯」（粵 ging1 wai5／普 jīngwěi）多半是經度緯度，或者比喻縱橫交錯；寫成 経緯けいいを説明せつめいする，意思是「交代來龍去脈」。
  • 発足ほっそく：組織、團體開始運作，如 新しい委員会いいんかいが発足ほっそくした。中文的「發足」很少用，所以字面容易被忽略。
  • 措置そち：措施。這個跟中文一樣，但日語多用在官方的行動。

不少詞是「看得懂但不會用」：你認得，卻不能用中文的習慣去搭配。每次碰到，順手記下它的搭配（検討けんとうを進すすめる 還是 検討けんとうを行う），比記單詞本身有用。

規則 5：標題是一種壓縮格式

標題要在很窄的版面內，用最少的字說最多的事，所以日本新聞形成了自己的一套省略法。先看一句：

しんえき、新車站（が） らいしゅんにも最快明春 かいぎょうへ將啟用

按一下整句聽聽：新駅、来春らいしゅんにも開業かいぎょうへ。

三個零件：

  1. 「、」代替 は 或 が：新駅、 就是「新車站（將會）」。
  2. にも 是「最快」：来春らいしゅんにも = 最快明年春天。這個 も 跟「也」無關。
  3. へ 是「朝著……去」：開業かいぎょうへ = 向開業的方向走，也就是「將要開業」。

全句還原成完整句子是：新しい駅が、来年の春はるにも開業かいぎょうする見通みとおしだ。省略掉的有主語助詞、動詞、句尾。

標題的八個常見手法

手法標題還原意思
① 逗號代助詞人口じんこう、10年連続ねんれんぞくで減少げんしょう人口じんこうが10年連続ねんれんぞくで減少げんしょうした。人口連續十年下降
② 体言止たいげんどめ（名詞結尾）バス運賃うんちん、4月から値上ねあげバスの運賃うんちんが4月から値上ねあげされる。巴士車費四月加價
③ へ：將要再開発さいかいはつ、計画けいかく見直みなおしへ再開発さいかいはつは、計画けいかくを見直みなおす方向ほうこうだ。重建計劃將重新檢討
④ も：最快年内ねんないにも再開さいかい年内ねんないにも再開さいかいする見通みとおしだ。最快年內重開
⑤ か：可能コメ価格かかく、高止たかどまりかコメの価格かかくは高い水準すいじゅんが続つづきそうだ。米價或繼續高企
⑥ 引言市長しちょう「再開発さいかいはつは見直みなおす」市長しちょうは「…」と述のべた。市長：重建會重新檢討
⑦ で：原因大雪おおゆきで一部いちぶ運転見合うんてんみあわせ大雪おおゆきのため、一部いちぶの電車が運転うんてんを見合みあわせている。因大雪，部分列車暫停
⑧ 長漢字詞壓縮与野党よやとう、法案ほうあんで対立たいりつ与党よとうと野党やとうが、法案ほうあんをめぐって対立たいりつしている。朝野就法案對立

第 ⑦ 個還有一個要注意的技巧：見合みあわせ（暫停、擱置）是新聞鐵路消息裏每天出現的詞。運転見合うんてんみあわせ 是「暫停行駛」，不是「讓車子互相看」。第 ⑧ 個的 与党よとう（執政黨）和 野党やとう（在野黨）合稱 与野党よやとう，政治版必備；跟第 25 章的 をめぐって 一樣，新聞很愛用它來寫對立。

小心！標題裏的「へ」、「も」、「か」

  • へ 不是「去某處」，是「將要」。閉店へいてんへ 是「將要關門」，不是「去關門」。
  • にも 是「最快」，不是「也」。来月にも = 最快下個月。
  • か 放在標題最後，是「或許」，不是疑問。首相しゅしょう、辞任じにんか 是報道有這個可能。
  • 標題的名詞結尾，時態要靠前文：値上ねあげ 可以是已加價，也可以是將加價，要看有沒有 から、へ 這類線索。
  • 標題用的不是敬體，也不是口語，是它自己的一套。不要以為這就是日語的正常句子，更不要在作文裏模仿。

英文幫到你：英文的新聞標題也一樣

英文報紙標題同樣不是正常句子：Mayor to quit（to = 將要，像 へ）、Fire kills 3（現在式代替過去式）、Shop owner held（省略 be 動詞）。你已經習慣英文標題的壓縮法，日語的 へ、か、体言止たいげんどめ 只是同一回事的另一個版本。連「冠詞和 be 動詞被省掉」這個原則都一樣。

削尖你的鉛筆：標題還原

每個標題之後有三個還原，選正確的一個。

  1. 駅前の商店街しょうてんがい、閉店へいてんへ
  2. 来月にも運賃うんちん値上ねあげ
  3. 首相しゅしょう、来月訪米ほうべいか
  4. 子どもの読書量どくしょりょう、倍増ばいぞう
答案

1 是第二個：へ 是方向；後面兩個把 へ 當成移動，或者加了意志，都不是標題的意思。

2 是「最快下個月加價」：にも 是 早はやければ 的意思。

3 是「首相可能下個月訪美」：か 是推測，所以不是「確定」。訪米ほうべい 是訪問美國，新聞常把國名縮成一個字（米べい 美、英えい 英、中 中、露ろ 俄）。

4 是「子ども的閱讀量增加了一倍」：倍増ばいぞう 是翻倍，不是減半。体言止たいげんどめ 的時態看上下文，這裏是已經發生的事。

規則 6：一篇新聞怎樣讀

新聞正文的結構叫「倒金字塔」：最重要的放在最前面，越往後越是細節。第一段（リード，英文 lead）幾乎已經包含全部要點：誰、何時、做了甚麼。後面幾段補充背景、數字、反應，隨時可以停下來。

所以讀日文新聞，有一個比逐字翻譯有效得多的辦法：先讀標題，再讀第一段，然後抓每段的第一句。要點通常在 〜は〜と発表はっぴょうした 這類句子裏，後面是理由或補充。N2 閱讀題的短文和中文常常是這個結構，第 29 章還會再回到這一點。

下面是一篇原創的虛構新聞（地名、數字都是編的），用了這一章的標題手法和句尾。先自己讀，不要查字典，按 ▶ 可以聽朗讀：

図書館としょかんの夜間開館やかんかいかん、来月から試行しこうへ

みどり市しは十日、市立図書館しりつとしょかんの開館時間かいかんじかんを来月から延長えんちょうすると発表はっぴょうした。平日へいじつは午後七時までだったが、週しゅう二日に限かぎり午後九時まで開あける。仕事帰しごとがえりに利用りようしたいという市民しみんの要望ようぼうを受うけた措置そちで、半年間の試行しこう結果けっかを踏ふまえ、本格実施ほんかくじっしするかどうかを決きめる方針ほうしんだ。

市しによると、昨年度さくねんどの利用者りようしゃは約やく三十万人で、五年前より約やく二割にわり減へった。特とくに二十代にじゅうだいから四十代よんじゅうだいの減少げんしょうが目立めだつという。市しの担当者たんとうしゃは「時間が合あわず、利用りようをあきらめていた人は多いのではないか」と話している。

人件費じんけんひが増ふえることから、市しは夜間やかんの運営うんえいを一部いちぶボランティアに頼たよることも検討けんとうしている。ただし、ボランティアの募集ぼしゅうは来月以降いこうになる見通みとおしだ。

考試熱身：N2 讀解 問題10 内容理解ないようりかい（短文たんぶん）

讀上面的新聞，回答問題。

  1. この記事きじの内容ないようと合あっているものはどれか。
    1. 図書館としょかんは来月から毎日午後九時まで開あく。
    2. 図書館としょかんは来月から、週しゅうに二日だけ夜よる遅おそくまで開あける。
    3. 図書館としょかんの利用者りようしゃは、五年前より二割にわり増ふえた。
    4. 夜間やかん開館かいかんはすべてボランティアが運営うんえいする。
  2. 市しが本格実施ほんかくじっしするかどうかを決きめる根拠こんきょは何か。
    1. 市民しみんが書いた手紙てがみの数かず
    2. ボランティアの人数にんずう
    3. 来年度らいねんどの予算よさん
    4. 半年間の試行しこう結果けっか
  3. 「利用りようをあきらめていた人は多いのではないか」と考かんがえているのは誰だれか。
    1. 市しの担当者たんとうしゃ
    2. 記者きしゃ
    3. ボランティアの人
    4. 市民しみん
答案

1 是 2：週しゅう二日に限かぎり = 限於每週兩天；選項 1 把「週二日」誤讀成每天。3 是減了兩成，不是增加。4 本文說的是「一部」ボランティア。

2 是 4：半年間の試行しこう結果けっかを踏ふまえ、本格実施ほんかくじっしするかどうかを決きめる。〜を踏ふまえ 是「根據、考慮到」，後面就是決定的依據。

3 是 1：括弧「」裏的話，後面是 と話している，主語是前面的 市しの担当者たんとうしゃ。新聞的規矩是引用都要標明誰說的，所以不會是記者自己的看法。

順帶一提，第一段的 措置そち（措施）是 N1 級的詞，不認得也不影響答題：這就是第 29 章要練習的「跳過生字」。

逐段拆解：每一段在做甚麼

回頭看那篇虛構報道，三段各有分工，這也是日本新聞最典型的寫法：

  1. 第一段（導語）：誰做了甚麼，何時，怎樣。みどり市しは……発表はっぴょうした 是事實，……方針ほうしんだ 是尚未確定的計劃。注意它同時含兩層：已經發生的（發表），和還沒有決定的（本格実施ほんかくじっしするかどうか）。把兩層分開，是讀新聞的第一個動作。
  2. 第二段（背景和數據）：用 〜によると 帶出資料，再用 〜という 帶出一個傳聞性的觀察（二十至四十歲的減少最明顯），最後用引言放入官員的意見。這一段回答「為甚麼要這樣做」。
  3. 第三段（補充和限制）：ただし 開頭，補上一個條件：志願者招募還在下個月以後。這是新聞最愛留的尾巴：把不確定的事放到最後。

你會發現，整篇文章沒有一句「我認為」。連最接近意見的一句，也是用引言放進市政府擔當者的口裏。這就是新聞日語的紀律：記者不表態，只轉述。要看記者的立場，要去看社論（第 32 章）。

數字、日期和稱呼

新聞的「小地方」也有講究，錯過會看錯意思：

  • 日期省略月份：みどり市しは十日、…… 的「十日」是這個月的十日，月份省略是因為讀者知道是今天前後的事。前面如果出現過月份，後面一律用 同月どうげつ、同日どうじつ。
  • 年度ねんど 不是 年：日本的財政年度和學年由四月開始，到翌年三月結束。昨年度さくねんど 是上一個會計年度（包括今年一月至三月），跟「去年」不同。中文沒有這個習慣，初學的人常常算錯月份，閱讀題裏的統計數字特別要小心。
  • 倍數和比率：二割にわり 是二成（20%），新聞多用 〜% 或 〜割わり。倍増ばいぞう（翻倍）、半減はんげん（減半）、急増きゅうぞう（急升）、横よこばい（持平）是標題常見的組合詞。
  • 人名的稱呼：一般人用 〜さん，政治家、學者、企業的負責人多用 〜氏し 或者「職銜＋名字」，被捕的人則稱 〜容疑者ようぎしゃ（嫌疑人），在判決之前不稱 犯人はんにん。各報章細節不一。

規則 7：である體寫文章

新聞之外，另一個你會碰到常體的地方，是評論、報告、論文。這類文章不是報道事實，而是要說服人，所以句尾多了一批「主張」專用的形狀：

  • 〜と考かんがえられる：可以認為。比 考かんがえる（我認為）客觀，因為主語被隱藏了。
  • 〜と言えるだろう／〜と言えよう：可以說。語氣保守，留有餘地。
  • 〜のではないだろうか：不是嗎？用反問表達自己的看法，語氣委婉，評論最愛用。
  • 〜に過すぎない：不過是。これは一部いちぶの例れいに過すぎない。
  • 〜のである：強調或說明理由。これは偶然ぐうぜんではない。必然ひつぜんなのである。
  • なぜなら〜からである：理由放在後面。なぜなら、費用ひようが高すぎるからである。

其中的 のである，來源就是你在第 11 章學的 んです（の + です）的書面版：んです 是對人解釋，のである 是在文章裏向讀者解釋。同一個功能，用不同的文體說。

用法上有一個值得提醒的細節：商務報告和公司文件，常在開頭先寫結論，後面用 なぜなら〜からである 補理由，日本人說「結論から」。如果你的日語商務報告沒有這個結構，讀的人會覺得結論來得太突然。這跟中文常見的「首先、其次、最後」有點不同。學術論文則不同：開頭放要旨（摘要），正文按序展開，結論多在最後。這些都是傾向，不是鐵則。

實際動手改寫一次，印象會深很多。下面是一封寫給同事的口語電郵，要改成報告裏的一段：

  • 原文：先週せんしゅうの会議かいぎ、やっぱり時間が足たりなかったんで、もっと長くしてほしいです。でも、予算よさんがないから難むずかしいかも。
  • 改成常體：先週せんしゅうの会議かいぎは、時間が足たりなかった。そのため、会議かいぎの時間を延長えんちょうすることが望のぞましい。ただし、予算よさんの制約せいやくがあるため、実現じつげんは難むずかしいと考かんがえられる。

對比之下，改寫做了五件事：やっぱり、もっと 刪掉或換掉；んで 還原成 ため；ほしいです（個人願望）改成 望のぞましい（客觀的「宜」）；でも 換成 ただし；難むずかしいかも（猜測）換成 難むずかしいと考かんがえられる。五個改動都是我們這一章的規則，沒有一個是新知識，只是要同時想到。這也是為甚麼寫作比閱讀難：閱讀時你只要認得，寫作時你要同時記起所有的書面版。

動動腦

為甚麼新聞不用「です・ます」？想想三個原因：讀者是誰？記者想給人甚麼印象？版面有多大？

常見的答案有三個：新聞的讀者不是一個特定的人，所以沒有「對誰有禮貌」的問題；記者希望文章顯得客觀，です・ます 帶著說話人和聽者的關係，會讓報道像在對你說話；最後是版面，だ・である 比 です・ます 短，同樣的位置能放更多字。至於哪一個是主要原因，不同的語言學者看法不一，三者都有影響。

配對遊戲：口語配書面

為每個口語詞語選出書面對應。

  1. だから →
  2. でも →
  3. もっと →
  4. やっぱり →
  5. とても →
  6. だんだん →
  7. やっと →
答案

だから → そのため、でも → しかし、もっと → さらに、やっぱり → やはり、とても → 非常ひじょうに、だんだん → 次第しだいに、やっと → ようやく。ただし 沒有口語對應，是補充條件時用的，所以不是答案。

考試熱身：N2 文法 問題9 文章ぶんしょうの文法ぶんぽう

下面是一篇報告的一部分。（1）至（3）放哪一個最合適？

社内しゃないアンケートの結果けっかについて

今回こんかいの調査ちょうさでは、社員しゃいんの七割ななわりが在宅勤務ざいたくきんむを続つづけたいと答こたえた。（1）、出社したいと考かんがえる人も三割さんわり程度ていどおり、意見いけんは分かれていると（2）。特とくに、新入社員しんにゅうしゃいんの間では、先輩せんぱいに気軽きがるに質問しつもんできないという声こえが目立めだつ。（3）、勤務きんむ形態けいたいは一律いちりつに決きめず、部署ぶしょごとに選えらべるようにするのが望のぞましい。

答案

（1）しかし：前面七成想繼續在家工作，後面說還有三成想回公司，是逆接。

（2）言える：文章是常體，句尾用 〜と言える（可以說）。言えます 是敬體，在這份報告裏文體不一致；言うだ 形狀不存在。

（3）したがって：從上面的結果推出建議，是順接。ただし 是補充例外，それとも 是「還是」，用於問句。

爐邊對談：です・ます vs だ・である

です・ます
我是「你」和「我」之間的橋樑。電郵、客服、說明書，哪裏有讀者，哪裏就有我。
だ・である
我不需要讀者。新聞、論文、法律，我只負責把事情記下來。
です・ます
聽起來有點冷漠。
だ・である
冷漠就是客觀。你想像一份判決書寫「請大家理解，被告有罪です」。
です・ます
……好吧，那樣的確很怪。不過說明書和電郵裏，我才是主角。

沒有蠢問題

日本人寫電郵、寫網誌，用的是哪一種？
電郵多數用敬體，網誌和 SNS 隨寫的人心情而定：有人全用敬體，有人用口語普通形，也有人「です・ます」和普通形夾雜著用。夾雜並不算錯，是一種風格。到了報告、論文才要嚴格統一。
日記該用甚麼？
多數人寫日記用普通形，因為是寫給自己看的。小學生的日記作業有時要求用敬體，那是學校的規定。
一篇文章裏可以同時有 です・ます 和 だ・である 嗎？
正式文章不可以，要選一種到底。唯一的例外是引用別人的話（在「」裏面可以是敬體）。N2 的閱讀文章裏，引用的部分文體不同是正常的，不是文章錯了。
我讀日文新聞很慢，有甚麼入門方法？
先讀標題和第一段，其餘跳過。NHK 的 NEWS WEB EASY（https://news.web.nhk/news/easy/）為日語學習者準備了簡化新聞，用的是接近常體的簡單句，是很好的過渡教材。

重點整理

  • 日語有三套文體：敬體（です・ます）、口語普通形、常體（だ・である）。常體用在新聞、論文、報告，不跟任何人說話。
  • 常體的名詞句和な形容詞句，句尾用 だ（較輕，新聞多用）或 である（較重，學術文章）；い形容詞和動詞沒有 だ。否定是 ではない，不用 じゃない。
  • 常體不能用口語縮寫（〜てる、〜ちゃう、〜じゃ）和語氣詞（よ、ね），連接詞和程度詞也要換成書面版：しかし、そのため、さらに、非常ひじょうに、次第しだいに。
  • 新聞句尾標明可信度和來源：〜した（事實）、〜という（傳聞）、〜とみられる（推定）、〜方針ほうしんだ／見通みとおしだ（預計）。
  • 標題用 、 代替 は／が，用体言止たいげんどめ，用 へ（將要）、にも（最快）、か（可能）。這是壓縮格式，不要在作文裏模仿。
  • 新聞常用 〜を受うけて、〜に伴ともない、〜を踏ふまえ、同どう〜。
  • 評論和報告用 〜と考かんがえられる、〜のではないだろうか、のである、なぜなら〜からである；日語商務報告往往先說結論。
