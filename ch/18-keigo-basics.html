第 18 章

敬語入門

你的です・ます已經很有禮貌，可惜站在收銀機後面，還差一大截。

山本店長，下北沢的咖啡店，開店前三十分鐘嘉欣カーヤンさん、開店かいてんの前に、ちょっと練習れんしゅうしましょう。わたしがお客様きゃくさまです。

嘉欣はい！

山本店長，扮客人推門進來すみません、二人です。

嘉欣いらっしゃいませ！二人ですね。こっちに座すわってください。

山本店長コーヒーを二つください。

嘉欣はい、わかりました。ちょっと待まってください。

山本店長，回到店長的語氣嘉欣カーヤンさん、文法ぶんぽうは全部ぜんぶ正ただしいです。でも、お客様きゃくさまには、それでは足たりません。

嘉欣，心想每一句都有です、ます，還不夠客氣？那要怎樣說？

店長說得對：嘉欣的日語沒有一個文法錯誤，放在朋友之間甚至算很有禮貌。可是在日本的店裏，店員對客人說話，用的是另一套語言。店長示範了一次：

嘉欣說的店長要的
二人ですね。二名様にめいさまですね。
こっちに座すわってください。こちらへどうぞ。
わかりました。かしこまりました。
ちょっと待まってください。少々しょうしょうお待まちください。

右邊這一欄就是敬語。換的不只是句尾，連詞語（ちょっと → 少々しょうしょう）、動詞的形狀（待まって → お待まち）、甚至整個動詞（わかる → かしこまる）都換掉了。

敬語是很多人學日語的噩夢，但這一章只做入門：三種敬語怎樣分工、兩條公式、十來個特別動詞，還有咖啡店和電話裏天天用到的句子。尊敬語和謙讓語的完整版，留待第 22 章。

規則 1：敬語有三種，看「誰的動作」

日語的敬語分三種：

  • 丁寧語：です、ます、ございます。對聽話的人有禮貌，誰的動作都可以用。你從第 3 章已經在用。
  • 尊敬語：把對方（客人、上司、老師）的動作抬高。只用在別人的動作上。
  • 謙讓語：把自己（和自己這一方）的動作壓低，間接抬高對方。只用在自己的動作上。

同一個「來」，看是誰來：

おきゃくさまが對方的動作 いらっしゃいました尊敬語：抬高

すぐに馬上 まいります謙讓語：我的動作，壓低

按一下聽聽：お客様きゃくさまがいらっしゃいました。（客人來了。）すぐに参まいります。（我馬上過來。）兩句的普通說法都是 来ます。

誰的動作用甚麼「來」
客人、上司、老師尊敬語いらっしゃいます
自己、自己公司的人謙讓語参まいります
不特別抬高誰丁寧語来ます

最重要的一句：尊敬語永遠不用在自己身上，謙讓語永遠不用在客人身上。中文腦最容易犯的錯，就是覺得「越客氣越好」，於是把尊敬語套在自己的動作上，結果變成「本人大駕光臨」。

敬語＝權限設定：尊敬語把對方 sudo 成 root，謙讓語把自己降成 guest，丁寧語是對外的預設權限。

中文腦：「貴」「敝」「光臨」，中文也有敬語

普通話只有一個語法上的敬語：「您」。粵語連「您」都沒有，客氣靠「請問」「麻煩你」「唔該」。所以很多中文讀者覺得敬語是全新的東西。

其實中文早有一整套敬語詞，只是平時少用：

  • 抬高對方（≈ 尊敬語）：貴公司、貴姓、府上、光臨。「歡迎光臨」正正就是 いらっしゃいませ。
  • 壓低自己（≈ 謙讓語）：敝公司、寒舍、拜讀、拜見。日語的謙讓語 拝見はいけんする（看），寫出來就是「拜見」。

日語連這些詞也有對應：御社おんしゃ（貴公司）、弊社へいしゃ（敝公司），求職面試必用。

不同之處在於規模。中文的「貴」「敝」只出現在書信和正式場合的固定說法；日語卻是連「吃」「看」「說」「在」這些日常動詞都有敬語版，而且在便利店、咖啡店每天都聽到。想像一下中文的「光臨」和「拜見」擴展到每一個動詞，就是日語敬語的規模。

規則 2：丁寧語升一級：ございます和店員詞彙

丁寧語你已經會：です、ます。在店裏，它還要再升一級：

  • あります → ございます：お手洗てあらいはあちらにございます。（洗手間在那邊。）
  • です → でございます：こちらが本日ほんじつのケーキでございます。（這是今天的蛋糕。）

你早就認識 ございます：ありがとうございます、おはようございます 裏都有它。

除了句尾，店員連日常詞語都會換成正式版本。這張表值得背下來，咖啡店、便利店、酒店前台全部通用：

平時說店裏說意思
ここ／そこ／あそこ／どここちら／そちら／あちら／どちら這裏／那裏／哪裏
だれどなた、どちら様さま誰
人方かた人、位
ちょっと少々しょうしょう稍為
いいよろしい可以、好
今日本日ほんじつ今天
あとでのちほど稍後
すみません申もうし訳わけございません對不起
わかりましたかしこまりました明白了、好的

名詞前面還常加 お 或 ご：お水、お名前、ご注文ちゅうもん、ご住所じゅうしょ。大致規律是：日本本土的詞（訓讀）加 お，漢語詞（音讀）加 ご。例外也不少，お電話、お時間じかん 都是漢語卻加 お，見一個記一個。

規則 3：尊敬語公式：お＋ます形＋になる

對方的動作要抬高，最常用的公式是：お ＋ ます形去掉 ます ＋ になる。

おきゃくさまは對方 おおかえりかえります 去 ますになりましたになる

按一下整句聽聽：お客様きゃくさまはもうお帰かえりになりました。（客人已經回去了。）

  • 待まつ → お待まちになる：こちらでお待まちになりますか。（您在這裏等嗎？）
  • 読む → お読みになる：先生はもうこの本をお読みになりました。（老師已經看過這本書。）
  • 使つかう → お使つかいになる：レジ袋ぶくろはお使つかいになりますか。（要用膠袋嗎？）

為甚麼是 になる（變成）？字面上，這句話不直接說客人「做」了甚麼，而是說事情「變成」客人回去了的狀態。不直接點出對方的動作，是日語客氣的一貫手法。

する 結尾的漢語動詞，改用 ご：利用りようする → ご利用りようになる。

請客人做事：お＋ます形＋ください

把 になる 換成 ください，就是店裏最常聽到的請求句。它比 ～てください 客氣得多：

  • 待まってください → 少々しょうしょうお待まちください。（請稍等。）
  • 座すわってください → どうぞお座すわりください。（請坐。）
  • 利用りようしてください → ご利用りようください。（歡迎使用。）
  • 注意ちゅういしてください → 足元あしもとにご注意ちゅういください。（請小心腳下。）

最後一句你在東京的車站一定聽過。下次聽到，留意那個 ご～ください。

公式有一個限制：ます形只剩一個假名的動詞（見ます、います、寝ねます）套不進去，沒有「お見になる」。這些動詞，還有幾個最常用的動詞，有自己的特別形。

規則 4：尊敬語的特別動詞

最常用的幾個動詞不跟公式，直接換成另一個詞。這幾個要硬背，好在數量不多：

普通尊敬語ます形例句
いる、行く、来るいらっしゃるいらっしゃいます山本さんはいらっしゃいますか。
食べる、飲む召めし上あがる召めし上あがりますどうぞ、召めし上あがってください。
言うおっしゃるおっしゃいますお名前は何とおっしゃいますか。
見るご覧らんになるご覧らんになりますこちらのメニューをご覧らんください。
くれるくださるくださいます先生が本をくださいました。
するなさるなさいますお飲のみ物ものは何になさいますか。

留意 ます形：いらっしゃる、おっしゃる、くださる、なさる 四個雖然是五段動詞，ます形卻是 ～います，不是「いらっしゃります」。店員每天說的 いらっしゃいませ、你天天用的 ください，就是從這裏來的。

くださる 你在第 13 章見過，是 くれる 的尊敬語，所以 ～てください 本身已經帶一點敬意。お飲のみ物ものは何になさいますか（您想喝甚麼？）和 お名前は何とおっしゃいますか（請問您貴姓大名？）這兩句，直接當成整句記住就最實用。

同一個問題，三個級別

把到目前為止學過的放在一起，看看同一句「店長在嗎？」在不同場合怎樣說：

對誰說說法級別
田中さん（朋友）店長てんちょう、いる？普通形
同事、陌生人店長てんちょうはいますか。丁寧語
客人、外人店長てんちょうはいらっしゃいますか。丁寧語＋尊敬語

第三句其實疊了兩層：いらっしゃる 抬高店長，ます 對聽話的人有禮貌。這兩層是分開的開關。跟朋友講到老師，可以說 先生、いらっしゃる？，尊敬語開著、丁寧語關掉，因為對老師有敬意，對朋友卻不用客套。反過來，跟客人講自己的事，丁寧語開著，尊敬語卻絕對不開。

記住這兩個開關，敬語就不再是一團霧：一個開關看「我在跟誰說話」，另一個開關看「我在講誰的動作」。

規則 5：謙讓語公式：お＋ます形＋する

輪到自己的動作。把公式裏的 になる 換成 する，就變成謙讓語：

おにもつを客人的行李 おおもちもちます 去 ますしますする：我的動作

按一下整句聽聽：お荷物にもつをお持もちします。（我幫您拿行李。）

  • 送おくる → お送おくりします：駅までお送おくりします。（我送您到車站。）
  • 知しらせる → お知しらせします：結果けっかはメールでお知しらせします。（結果會用電郵通知您。）
  • 待まつ → お待まちします：またのご来店らいてんをお待まちしております。（期待您再次光臨。）

漢語動詞同樣改用 ご：ご案内あんないします（帶位、介紹）、ご説明せつめいします、ご連絡れんらくします。お電話します 又是加 お 的例外。想再客氣一點，把 します 換成 いたします：お席せきにご案内あんないいたします。（我帶您入座。）

謙讓語公式也有限制：只用於跟對方有關的動作，例如替對方拿東西、通知對方、等對方。自己一個人走路、睡覺，不會說「お歩きします」。

兩條公式並排看，分別只在最後一截：

尊敬語（對方做）謙讓語（我做）
公式お～になるお～する
待まつお待まちになる（您等）お待まちする（我等您）
漢語ご利用りようになるご案内あんないする
請求お待まちください（不會請自己做事）

削尖你的鉛筆

先問一句「這是誰的動作」，再選出正確的說法。全部都是嘉欣在店裏說的話。

  1. お客様きゃくさま、こちらで少々しょうしょう
  2. （嘉欣幫客人拿行李）お荷物にもつを
  3. あちらのお客様きゃくさまは、もう
  4. お席せきに
  5. 店長てんちょう、新しいメニューを
  6. （客人叫嘉欣過去）はい、すぐに
答案

1 お待まちください、2 お持もちします、3 お帰かえりになりました、4 ご案内あんないします、5 ご覧らんになりましたか、6 参まいります。

第 1 題是最多人犯的錯：お待まちする 是「我等您」，加 てください 就變成「請您謙卑地等」，方向全錯。第 5 題對象是店長，看菜單的也是店長，所以用尊敬語；拝見はいけんする 是下一節的謙讓語，只能用在自己身上。第 6 題是自己走過去，用謙讓語。

規則 6：謙讓語的特別動詞

謙讓語也有一批特別動詞。其中幾個你其實早就會說：

普通謙讓語例句意思
行く、来る参まいるすぐに参まいります。我馬上過來。
言う申もうす嘉欣カーヤンと申もうします。我叫嘉欣。
食べる、飲む、もらういただく先生にお土産みやげをいただきました。老師送了我手信。
見る拝見はいけんする切符きっぷを拝見はいけんします。請出示車票。（字面：讓我看看車票）
いるおる山本はただいま外出しております。山本現在外出了。
するいたす失礼しつれいいたします。打擾了／先走了。

～と申もうします 你在第 3 章自我介紹時當作整句學過，原來它是 言う 的謙讓語。いただきます 是飯前說的那句，字面是「我謙卑地領受了」。よろしくお願ねがいします 也可以升級成 よろしくお願ねがいいたします，電郵結尾最常見。

還有 おる：它常接在 て形後面，代替 ～ている。外出しています → 外出しております，お待まちしています → お待まちしております。電話和電郵裏，～ております 多得數不完。第 13 章的 さしあげる（あげる 的謙讓語）也屬於這一組。

配對遊戲

每個動詞配上它的特別敬語。括號說明要尊敬語還是謙讓語。

  1. いる（尊敬語） →
  2. 食べる（尊敬語） →
  3. 言う（尊敬語） →
  4. 見る（尊敬語） →
  5. 行く（謙讓語） →
  6. 言う（謙讓語） →
  7. 見る（謙讓語） →
  8. もらう（謙讓語） →
  9. いる（謙讓語） →
  10. する（謙讓語） →
答案

尊敬語：いる → いらっしゃる、食べる → 召めし上あがる、言う → おっしゃる、見る → ご覧らんになる。

謙讓語：行く → 参まいる、言う → 申もうす、見る → 拝見はいけんする、もらう → いただく、いる → おる、する → いたす。

記憶小技巧：いらっしゃる、おっしゃる 都有 っしゃ，聽起來華麗，是抬高別人的；申もうす、参まいる、おる 短而樸素，是壓低自己的。

小心！方向搞錯，比不用敬語更糟

敬語的錯誤，多數不是形狀錯，而是方向錯：

  • ✗ わたしは今、店みせにいらっしゃいます。 → ○ わたしは今、店みせにおります。（自己的動作不能抬高。）
  • ✗ お客様きゃくさま、お待まちしてください。 → ○ お待まちください。（お～する 是謙讓語，不能拿來請客人做事。）
  • ✗ メニューを拝見はいけんしてください。 → ○ メニューをご覧らんください。
  • ✗ こちらのカードをご利用りようしてください。 → ○ ご利用りようください。（這個錯連日本人也常犯。）

另一個陷阱是雙重敬語：おっしゃる 已經是尊敬語，再加尊敬的 られる 變成「おっしゃられる」，就是疊床架屋。一個動詞，敬一次就夠。

規則 7：咖啡店的一整套敬語

店裏的敬語其實是一套劇本。日本的連鎖店會把它印成手冊，新員工第一天就要背熟。嘉欣的版本是這樣的，按每一句聽聽：

時刻店員說意思
客人進門いらっしゃいませ。何名様なんめいさまですか。歡迎光臨。請問幾位？
帶位こちらへどうぞ。這邊請。
點餐ご注文ちゅうもんはお決きまりですか。決定好點甚麼了嗎？
點飲品お飲のみ物ものは何になさいますか。您想喝甚麼？
收到かしこまりました。少々しょうしょうお待まちください。好的，請稍等。
上餐お待またせいたしました。ホットコーヒーでございます。讓您久等了，這是熱咖啡。
放下就走ごゆっくりどうぞ。請慢用。
結帳お会計かいけいは八百円でございます。一共八百円。
收錢千円お預あずかりします。收您一千円。
找錢二百円のお返かえしです。找您二百円。
送客ありがとうございました。またお越こしくださいませ。謝謝，歡迎再來。

留意幾個你已經拆得開的零件。お待またせいたしました 是第 17 章的使役 待またせる，套進謙讓語 お～いたす。お預あずかりします 是謙讓語公式。お越こしください 是 来る 的另一個尊敬說法，當成整句記住就好。

還有一種形狀：お決きまりですか。這是 お ＋ ます形 ＋ です，也是尊敬語，比 お～になる 短，店裏很愛用：ポイントカードはお持もちですか。（有積分卡嗎？）店内てんないでお召めし上あがりですか。（在店內用餐嗎？）第二句在快餐店和咖啡店幾乎每天都聽到，答 はい 或者 持もち帰かえりで（外賣）就可以。

便利店的劇本更短，零件卻一樣。第 1 章嘉欣聽不懂的 お弁当べんとう、温あたためますか 只是丁寧語；店員接著常會問 お箸はしはおつけしますか（要不要筷子？）。おつけする 是 つける（附上）的謙讓語，因為附上筷子的是店員自己。聽到 お～しますか，就知道店員在問「要我替你做這件事嗎」，答 お願ねがいします 或 けっこうです（不用了）就可以。

削尖你的鉛筆

嘉欣的句子文法沒錯，但不夠「店員」。選出店長會用的說法。

  2. 何人ですか。 → ですか。
  3. わかりました。 →
  4. すみません、今日はもう終おわりです。 → 、本日ほんじつはもう終おわりでございます。

答案

1 あちら、2 何名様なんめいさま、3 かしこまりました、4 申もうし訳わけございません、5 よろしいでしょうか、6 のちほど。

第 3 題的 おわかりになりました 形狀沒錯，卻是尊敬語，抬高的是「明白了」的自己，方向錯了。第 2 題的 名めい 是數人的正式助數詞，加上 様さま 就是對客人的說法。

規則 8：電話敬語和「內外」之分

第 13 章說過，日語把人分成「自己這一方」（ウチ）和「外人」（ソト）。敬語也跟著這條線走：對外人講自己這一方的人，用謙讓語，而且不加 さん。

平時嘉欣對店長說：店長てんちょう、何時ごろお戻もどりになりますか。（店長，您大約幾點回來？）店長是上司，用尊敬語。

可是供應商打電話來找店長，嘉欣就要換一套：

山本は自己人：不加 さん ただいま現在（正式） 外出して外出 おります謙讓語

按一下整句聽聽：申もうし訳わけございません。山本はただいま外出しております。（不好意思，山本現在外出了。）

對供應商來說，嘉欣和店長是同一方，所以店長的動作也要壓低。說成 山本店長てんちょうはいらっしゃいません，等於在外人面前抬高自己公司的人，日本人聽了會皺眉。中文說「我們陳經理不在」，加不加「經理」都沒問題；日語卻要把名字後面的稱呼一併拿走。

電話還有自己的開場白和收尾。店員接電話不說 もしもし，而是：

  • お電話ありがとうございます。カフェ・ミモザでございます。（多謝來電，這裏是 Café Mimosa。）
  • 失礼しつれいですが、どちら様さまでしょうか。（不好意思，請問是哪位？）
  • 戻もどりましたら、こちらからお電話いたしましょうか。（等他回來，由我們打給您好嗎？）
  • 失礼しつれいいたします。（那麼，再見。掛線前說。）

打電話的一方則會先報上名字：ABC食品しょくひんの木村きむらと申もうしますが、山本店長てんちょうはいらっしゃいますか。對木村先生來說，山本是外人，所以他用尊敬語 いらっしゃいます，還可以加上「店長」。同一個人，在不同人口中有不同待遇，這就是內外之分。

削尖你的鉛筆：接電話

木村先生打電話到咖啡店找店長。替嘉欣選出每一句的正確說法，再把嘉欣的五句連起來讀一遍，用錄音功能錄下來，跟答案的 ▶ 比較。

  1. （電話響起）
  2. 木村：ABC食品しょくひんの木村きむらと申もうします。山本店長てんちょうはいらっしゃいますか。
  3. 木村：何時ごろお戻もどりになりますか。
  4. 木村：そうですか。
  5. 木村：では、お願ねがいします。

選完了？把嘉欣的五句連起來，大聲讀一次並錄音：

答案
  1. お電話ありがとうございます。カフェ・ミモザでございます。
  2. 申もうし訳わけございません。山本はただいま外出しております。
  3. 三時ごろ戻もどる予定よていです。
  4. 戻もどりましたら、こちらからお電話いたしましょうか。
  5. かしこまりました。山本に伝つたえておきます。

第 2、3 題的錯誤選項都把尊敬語用在自己人（店長）身上，這正是規則 8 的陷阱。第 3 題的 予定よていです 是第 15 章學的「預定」，講自己人的行程最穩陣。第 4 題的 お電話してください 用謙讓語請客人做事，方向又錯了。第 5 題的 ～ておきます 是第 16 章的「事先做好」，在這裏是「我會轉告他」。

讀的時候留意節奏：ございます、おります 不用讀得很快，清楚、平穩，就是最專業的電話聲音。

考試熱身：N4 文法 問題1

N4 的敬語題通常考兩件事：特別動詞認不認得，以及方向對不對。先看主語是誰，再選答案。

（　）に 何を 入れますか。1・2・3・4から いちばん いい ものを 一つ えらんで ください。

  1. 先生は 何時ごろ 学校がっこうに（　）か。
  2. はじめまして。ワンと（　）。どうぞ よろしく おねがいします。
  3. 店員：「少々しょうしょう（　）ください。」
  4. 「先生、この 写真しゃしんを もう（　）か。」
  5. 「お荷物にもつ、わたしが（　）。」
  6. （電話で）「山本は ただいま 外出して（　）。」
答案

1 いらっしゃいます、2 申もうします、3 お待まち、4 ご覧らんになりました、5 お持もちします、6 おります。

第 1、4 題主語是老師，用尊敬語；第 2、5、6 題主語是自己或自己人，用謙讓語。第 4 題的 ごらんしました 是不存在的混合體：ご覧らん 只跟 になる 或 ください 一起用。第 6 題的 ございます 用於物件，おります 才用於人。

沒有蠢問題

日本人自己也覺得敬語難嗎？
難。日本公司會為新員工辦敬語培訓，書店有整排敬語書，連電視節目也會拿名人的錯敬語來取笑。好消息是，外國人說錯，日本人通常很寬容；只要方向對（抬客人、壓自己），形狀有點錯也聽得懂，而且會感受到你的誠意。
我在便利店常聽到「こちらコーヒーになります」「千円からお預かりします」，課本卻沒有教？
這類說法叫「打工敬語」，在日本的餐廳和便利店非常普遍，但語言專家常批評它不規範。コーヒーになります 字面是「會變成咖啡」，規範說法是 コーヒーでございます；千円から 的 から 也是多餘的。聽得懂就好，考試和面試用規範版。
我聽過 先生が来こられます，這不是第 17 章的受身形嗎？
形狀一樣，這裏卻是尊敬語。れる、られる 除了被動和可能，還可以表示輕度的尊敬，公司裏同事之間很常用：部長ぶちょうは何時に帰かえられますか。敬意比 お～になる 輕一點。詳細用法留待第 22 章。
對朋友也用敬語，豈不是更有禮貌？
剛好相反。敬語代表距離，對田中さん 這樣的朋友用 いらっしゃいます，聽起來像在說「我們不熟」，甚至有點諷刺。第 11 章的普通形才是朋友之間的語言。分寸在於看對象：對朋友用普通形，對陌生人和一般場合用丁寧語，對客人和上司加上尊敬語和謙讓語。
店長說的 お客様きゃくさま 和平時的 お客きゃくさん 有甚麼分別？
都是「客人」。お客様きゃくさま 是店員當面稱呼客人、或者正式場合的說法；お客きゃくさん 比較隨意，店員之間私下講、或者小店老闆對熟客會用。在店裏面對客人，一律用 お客様きゃくさま。

重點整理

  • 敬語有三種：丁寧語（です、ます、ございます）、尊敬語（抬高對方的動作）、謙讓語（壓低自己的動作）。
  • 選哪一種，看「誰的動作」：尊敬語永遠不用在自己身上，謙讓語永遠不用在客人身上。
  • 店員詞彙：こちら、少々しょうしょう、よろしい、本日ほんじつ、のちほど、かしこまりました、申もうし訳わけございません。
  • 尊敬語公式：お～になる（漢語用 ご～になる）；請求用 お～ください、ご～ください。
  • 尊敬語特別動詞：いらっしゃる、召めし上あがる、おっしゃる、ご覧らんになる、くださる、なさる。ます形是 ～います。
  • 謙讓語公式：お～する、ご～する，更客氣用 いたす。只用於跟對方有關的動作。
  • 謙讓語特別動詞：参まいる、申もうす、いただく、拝見はいけんする、おる、いたす。
  • 對外人講自己這一方的人：用謙讓語，名字後面不加 さん：山本はただいま外出しております。
  • 店員接電話說 お電話ありがとうございます。～でございます，不說 もしもし。
